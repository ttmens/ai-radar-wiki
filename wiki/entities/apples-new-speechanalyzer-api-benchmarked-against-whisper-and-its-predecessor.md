# Apple's new SpeechAnalyzer API, benchmarked against Whisper and its predecessor

## 中文摘要
Apple 发布了新的 SpeechAnalyzer API，并与 OpenAI 的 Whisper 及前代方案进行了基准测试对比。技术要点：新 API 在语音转文本准确率、延迟和隐私保护（本地处理）上表现突出，有望提升 Siri、听写等功能的体验。商业价值：Apple 自研语音技术降低对外部依赖，强化生态控制力，为开发者提供更强大的本地语音分析能力，推动语音交互产品创新。产品创新：该 API 实现了更精细的语音特征提取和分析，支持实时场景。
