# Agentic coding deserves more than a chat box bolted onto VS Code

## 中文摘要
当前AI编码工具（如Copilot）大多以聊天框形式嵌入VS Code，但真正的代理式编码（Agentic Coding）需要更深度的IDE集成与自主执行能力，而非简单的对话界面。这篇文章探讨了代理式编码的技术演进方向，强调从被动问答转向主动计划、执行与调试，提升开发者效率。商业价值在于创新产品形态可降低开发门槛，同时带来新的付费机会。产品创新点包括将AI从辅助工具升级为开发伙伴，实现代码生成、重构、测试等全流程自动化。
