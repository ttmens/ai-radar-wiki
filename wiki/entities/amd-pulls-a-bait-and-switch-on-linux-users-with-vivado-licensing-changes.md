# AMD pulls a bait-and-switch on Linux users with Vivado licensing changes

## 中文摘要
AMD调整了Vivado（FPGA设计套件）的许可政策，对Linux用户实施“诱饵调包”策略。此前Linux版Vivado曾提供一些免费或低价许可，新政策取消了这些优惠，迫使Linux用户转向更昂贵的付费方案。此举可能影响使用AMD FPGA进行AI加速的开发者群体，增加其开发成本与迁移风险。对于依赖FPGA进行边缘AI推理或可重构计算的产品团队，需重新评估供应商锁定成本，并考虑替代方案如Intel/Altera或开源工具链。该变化也凸显了硬件生态中许可策略对AI产品长期部署的影响。
