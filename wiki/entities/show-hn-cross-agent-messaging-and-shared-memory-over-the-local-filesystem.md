# Show HN: Cross-agent messaging and shared memory over the local filesystem

## 中文摘要
该项目通过本地文件系统实现跨智能体的消息传递与共享记忆，为多Agent协作提供了一种轻量级、去中心化的方案。它利用文件作为持久化媒介，支持Agent间异步通信和上下文共享，降低了对外部基础设施的依赖。产品创新在于将文件系统作为统一的消息总线和记忆存储，适合本地优先、隐私敏感的场景。商业价值体现在简化Agent集群部署成本，增强系统鲁棒性，尤其适用于边缘计算和个人化AI助手生态。
