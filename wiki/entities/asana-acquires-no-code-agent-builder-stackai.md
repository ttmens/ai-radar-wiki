# Asana acquires no-code agent-builder StackAI

## 中文摘要
Asana 宣布收购无代码智能体构建平台 StackAI，将其整合到不断扩展的 AI 工作流工具套件中。此举旨在让用户无需编程即可创建和部署 AI 助手，自动化项目管理、任务分配、流程审批等重复性工作。StackAI 的技术将增强 Asana 的智能工作流能力，降低企业采用 AI 的门槛，提升团队协作效率。对于 AI 产品经理而言，这是“无代码 + Agent 模式”在产品协作领域的典型应用，体现了大模型落地于企业 SaaS 的可行路径，具有重要的商业和产品创新价值。
