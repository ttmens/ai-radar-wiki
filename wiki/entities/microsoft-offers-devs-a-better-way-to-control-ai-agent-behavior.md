# Microsoft offers devs a better way to control AI agent behavior

## 中文摘要
微软推出了一项新规范，允许开发者、合规及安全团队通过可移植的策略文件为AI代理定义行为规则。该方案支持将控制策略与代理逻辑分离，确保代理在不同环境中遵循统一的合规与安全要求。其商业价值在于降低企业部署AI代理时的治理风险，提升可审计性和灵活性；产品创新体现在将策略管理标准化、可移植化，使非技术团队也能参与代理行为定义。
