# Show HN: Lathe – Use LLMs to learn a new domain, not skip past it

## 中文摘要
Lathe 是一个利用大语言模型（LLM）辅助学习的工具，其核心理念是帮助用户深入学习一个领域，而非直接跳过学习过程。与常见的“AI替你做事”不同，Lathe 通过引导式问答、逐步解释和交互练习，让用户在探索中构建知识体系。该产品定位为教育辅助工具，适合希望掌握新领域技能的用户，尤其适合需要系统学习而非碎片化信息获取的场景。其商业价值在于填补了AI教育中“促进理解”而非“替代思考”的市场空白，具有差异化优势。产品创新在于重新定义了AI在学习中的角色——从答案生成器转变为学习伙伴。
