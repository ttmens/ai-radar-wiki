# No, everyone is not using AI for everything

## 中文摘要
本文指出，尽管AI被广泛宣传，但并非所有领域或用户都在全面使用AI。产品经理应警惕炒作，理性评估AI的实际能力和适用场景。文章强调，盲目追求“AI赋能”可能导致资源浪费和产品偏离核心需求。技术要点在于理解AI的局限性，商业价值在于避免过度投资，产品创新应聚焦于解决真实问题而非堆砌AI功能。
