# Universal Memory Protocol – a shared format for agent memory

## 中文摘要
Universal Memory Protocol 提出了一种通用记忆共享格式，旨在让不同 AI 智能体之间标准化存储和交换长期上下文。该协议通过统一记忆表示与接口，使智能体能够跨平台保留用户偏好、历史行为和决策逻辑，从而提升对话连续性、个性化推荐和多任务协作能力。对 AI 产品经理而言，这意味着降低集成不同记忆系统时的工程成本，加快构建具备持久记忆的智能助手产品，并有望催生围绕记忆生态的第三方服务与工具链。
