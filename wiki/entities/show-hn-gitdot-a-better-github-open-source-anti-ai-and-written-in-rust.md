# Show HN: Gitdot – a better GitHub. Open-source, anti-AI, and written in Rust

## 中文摘要
Gitdot 是一个开源的 GitHub 替代品，采用 Rust 编写，宣称“反 AI”，即不集成 AI 辅助功能（如代码补全、自动 PR 摘要等），强调传统、纯粹的手动版本控制体验。该项目旨在吸引对 AI 持怀疑态度或担心代码数据被训练的开发者。Rust 语言带来高性能和内存安全，但功能完整性和社区生态尚不如 GitHub。对 AI 产品经理而言，其“反 AI”立场可作为市场分化信号，但整体 PM 相关性较低，因为它拒绝 AI 整合。
