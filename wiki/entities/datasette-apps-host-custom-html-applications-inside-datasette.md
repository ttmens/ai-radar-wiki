# Datasette Apps: Host custom HTML applications inside Datasette

## 中文摘要
Datasette Apps 允许用户在 Datasette 数据探索平台中直接托管自定义 HTML 应用程序，将数据分析与交互式界面深度融合。技术要点：通过插件机制，开发者可在 Datasette 内运行全功能 Web 应用，复用其数据 API 与权限模型。商业价值：降低构建数据驱动工具的门槛，适合快速原型、内部仪表盘或轻量级 AI 应用展示。产品创新：打破传统 BI 工具的局限，让数据平台本身成为应用运行环境，提升团队协作效率。
