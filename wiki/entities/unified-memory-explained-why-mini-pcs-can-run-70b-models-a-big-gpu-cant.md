# Unified Memory, Explained: Why Mini PCs Can Run 70B Models a Big GPU Can't

## 中文摘要
本文解释了统一内存（Unified Memory）架构如何让迷你PC（如Apple M系列）运行70B参数大模型，而传统大GPU受限于独立显存容量无法加载。统一内存允许CPU和GPU共享系统内存，从而突破显存瓶颈，使得低成本设备也能本地运行大规模模型。对AI产品经理而言，这降低了硬件门槛，推动边缘计算和隐私保护应用，并可能改变云端与终端部署的平衡。
