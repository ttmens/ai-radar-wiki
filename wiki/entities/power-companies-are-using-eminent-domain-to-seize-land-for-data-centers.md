# Power companies are using eminent domain to seize land for data centers

## 中文摘要
电力公司正利用征用权为数据中心强行征用土地，反映AI算力扩张对能源和土地资源的巨大需求。这一趋势将推高数据中心建设成本与交付周期，影响AI产品部署的可行性和地域选择。产品经理需关注由此引发的合规风险、能源成本上升以及边缘计算等替代方案的发展，以优化产品的基础设施策略。
