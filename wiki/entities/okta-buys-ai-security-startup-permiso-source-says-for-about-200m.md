# Okta buys AI security startup Permiso — source says for about $200M

## 中文摘要
Okta以约2亿美元收购AI安全初创公司Permiso，获得身份威胁检测能力，帮助企业在云环境中保护AI代理及其他非人类身份的安全。此举弥补了Okta在AI身份安全领域的空白，满足企业应对AI代理、服务账户等非人类实体安全威胁的需求。对AI产品经理而言，这揭示了未来AI基础设施中身份与权限管理的核心地位——AI代理的安全防护不再只是传统IAM的延伸，而是需要专门的威胁检测与实时响应能力。此次收购也反映了大厂通过并购快速补齐AI安全能力的趋势。
