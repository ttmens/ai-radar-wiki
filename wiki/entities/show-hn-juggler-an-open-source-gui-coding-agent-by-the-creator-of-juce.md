# Show HN: Juggler – an open-source GUI coding agent, by the creator of JUCE

## 中文摘要
Juggler 是一款开源 GUI 编码代理，由知名 C++ 音频框架 JUCE 的创建者开发。它通过 AI 自动理解和操作图形用户界面，实现桌面应用的自动化编码与交互。技术要点包括：基于 LLM 的 GUI 元素识别与事件模拟，支持跨平台桌面应用；开源模式降低了开发者定制和集成门槛。商业价值在于提升 UI 自动化测试、RPA 及低代码开发的效率，尤其适合需要频繁操作 GUI 的工程团队。产品创新在于将编码代理从纯代码生成扩展到 GUI 层面，开辟了 AI+UI 自动化新方向。
