# AI is code – and can't be prompted into being smarter

## 中文摘要
该文章指出AI本质上是由代码构成的系统，无法仅通过提示工程（prompting）使其变得更智能。对于AI产品经理而言，这提醒了产品设计中不能过度依赖提示词优化来提升AI能力，而应关注底层模型架构、训练数据和算法改进。商业价值在于避免将资源浪费在无效的提示调优上，转而投资更根本的技术突破。产品创新应着眼于模型能力边界之外的产品体验设计，例如结合外部知识库、工具调用或人工干预。
