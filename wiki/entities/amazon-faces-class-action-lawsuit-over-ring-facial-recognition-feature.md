# Amazon faces class action lawsuit over Ring facial-recognition feature

## 中文摘要
亚马逊旗下Ring门铃的“熟悉面孔”功能因未经同意存储路人面部图像，被用户提起集体诉讼。该功能利用AI人脸识别技术自动标记访客，但涉嫌违反隐私法规，反映了AI产品在用户数据收集与同意机制上的法律风险。对AI产品经理而言，需关注人脸识别等敏感功能的合规设计，确保用户明确授权，并建立数据生命周期管理策略，避免类似诉讼对品牌和业务造成影响。
