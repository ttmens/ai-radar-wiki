# SDL_GPU minimal, single-header, high-performance 2D graphics painting library

## 中文摘要
这是一个轻量级、单头文件、高性能的2D图形绘制库SDL_GPU，专为GPU加速设计，旨在提供极简的API和高效的渲染性能。虽然直接用途偏向游戏或图形界面开发，但对于AI产品经理而言，它可作为构建AI可视化工具、实时数据仪表盘或交互式模型展示的基础设施，降低2D图形渲染的开发门槛，提升产品交互体验。该库强调跨平台支持和最小依赖，适合嵌入到AI应用生态中作为图形层组件。
