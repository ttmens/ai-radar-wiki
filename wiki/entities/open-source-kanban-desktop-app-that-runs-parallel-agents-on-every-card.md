# Open source Kanban desktop app that runs parallel agents on every card

## 中文摘要
这是一款开源看板桌面应用，创新地在每张任务卡片上集成并行AI代理。每个代理可独立执行自动化操作（如数据检索、生成报告、代码审查等），实现任务级智能并行处理。产品降低了项目管理中引入AI的门槛，团队无需复杂配置即可通过看板驱动多个AI协同工作。其商业价值在于提升团队效率、支持自动化工作流，尤其适合敏捷开发和知识密集型任务。开源特性有利于定制和生态扩展。
