# When I reject AI code even if it works

## 中文摘要
该Hacker News帖子讨论开发者拒绝AI生成的代码，即使功能正确。核心问题是AI代码虽能运行，但可能缺乏可读性、可维护性、安全性或符合团队规范，导致被人类开发者拒绝。这反映了当前AI编程助手在代码质量、上下文理解与工程实践上的局限性。对AI产品经理而言，需要关注如何提升AI代码的“可接受度”，而不仅是功能正确性，包括集成代码审查、风格适配、架构一致性等产品创新。商业价值在于提高开发者信任和效率，推动AI辅助开发的落地。
