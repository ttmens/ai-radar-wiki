# The Smallest Brain You Can Build: A Perceptron in Python

## 中文摘要
本文介绍了用Python实现的最小‘大脑’——感知机（Perceptron），一种最简单的神经网络单元。通过理解其工作原理（线性分类、权重更新），产品经理可把握AI基础能力边界：感知机仅能解决线性可分问题，无法处理异或（XOR）等非线性场景。这提示在设计AI产品时，需根据任务复杂度选择合适模型，避免因基础模型局限导致产品效果偏差。感知机是理解更复杂网络（如多层感知机、深度学习）的起点，有助于评估技术可行性与成本。
