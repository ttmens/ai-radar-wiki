# Show HN: Capn-hook for coding agents – don't grep the same mystery twice

## 中文摘要
Capn-hook 是一个面向 AI 编码代理的工具，旨在避免重复搜索相同的疑难问题（mystery）。它通过持久化存储和自动匹配先前遇到的异常或错误模式，让代理能快速复用历史解决方案，减少无用 grep 操作。该工具可显著提升编码代理的长期记忆能力，降低人工干预频率，适用于需要持续调试或维护的 AI 辅助开发场景。产品创新点在于将“经验缓存”机制引入代理工作流，形成类似人类程序员的“直觉式”问题定位能力。
