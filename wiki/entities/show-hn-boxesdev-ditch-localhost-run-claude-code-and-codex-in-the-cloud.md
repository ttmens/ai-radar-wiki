# Show HN: Boxes.dev: ditch localhost; run Claude Code and Codex in the cloud

## 中文摘要
Boxes.dev 是一个云端开发环境平台，允许开发者直接在线运行 Claude Code 和 Codex 等 AI 代码助手，无需本地配置。该产品解决了本地开发环境依赖重、协作难的问题，通过预置的云 IDE 降低 AI 编程工具的使用门槛。对 AI 产品经理而言，它展示了将 AI 能力深度集成到开发工作流中的新范式，可能推动开发者工具从本地化向云原生+AI 原生转型，商业价值在于提升团队协作效率和 AI 助手的可访问性。
