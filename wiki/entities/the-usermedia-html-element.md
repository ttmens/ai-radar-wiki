# The <Usermedia> HTML Element

## 中文摘要
HTML 新增 <usermedia> 元素，旨在标准化浏览器端用户媒体（摄像头、麦克风）的访问与交互。该元素可简化 AI 产品中实时音视频输入的管理，降低开发者门槛，提升跨浏览器兼容性。对 AI 产品经理而言，这意味着更便捷地集成语音助手、视频分析、实时翻译等功能，减少对第三方库的依赖，有望加速浏览器端 AI 应用的落地。
