# Show HN: Agent Draw: An agent draws while you talk, built on TLDraw

## 中文摘要
Agent Draw 是一个基于 TLDraw 构建的实时 AI 绘图代理，用户可通过语音与之交互，在说话的同时自动绘制图形。技术核心在于将语音识别、自然语言理解与白板绘图引擎深度集成，实现边聊边画的无缝体验。该产品降低了创意表达和协作的门槛，可应用于在线教育、头脑风暴、产品原型快速展示等场景，展示了AI从“聊天”到“视觉化创作”的模式创新。
