# Kuna: Decompiler Development in the Age of Coding Agents

## 中文摘要
Kuna 是一个在 AI 编码 Agent 时代开发的现代反编译器项目，旨在提升代码逆向工程能力。它利用大语言模型和智能 Agent 技术，将二进制或低级代码高效还原为可读的高级语言源码，从而辅助开发者理解和调试遗留系统。该工具可集成到编码 Agent 工作流中，增强 Agent 对底层实现的分析能力，具有提升代码安全审计、迁移和自动化修复的商业价值。其产品创新在于将传统反编译与 AI 推理相结合，降低逆向门槛，为 AI 驱动的开发工具链提供关键基础设施。
