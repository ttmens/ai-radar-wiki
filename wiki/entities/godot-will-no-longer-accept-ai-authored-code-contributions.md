# Godot will no longer accept AI-authored code contributions

## 中文摘要
Godot 开源游戏引擎社区宣布不再接受 AI 编写的代码贡献，理由包括版权不确定性、代码质量难以保证以及社区信任问题。这一决策反映了 AI 辅助编程在开源生态中面临的治理挑战。对产品经理而言，需关注 AI 生成内容的合规性、协作流程变化及开发者社区对 AI 工具的态度，从而在引入 AI 功能时平衡创新与社区规范。
