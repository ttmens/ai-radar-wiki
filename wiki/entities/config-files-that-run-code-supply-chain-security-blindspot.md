# Config Files That Run Code: Supply Chain Security Blindspot

## 中文摘要
本文讨论配置文件（如YAML、JSON、TOML等）中嵌入代码执行引发的供应链安全盲点，攻击者可利用CI/CD配置、包管理脚本或环境变量注入恶意代码，绕过传统安全扫描。对AI产品经理而言，需关注AI模型依赖的开源库或配置文件（如模型训练配置、推理服务配置）是否存在类似风险，建议引入配置审计与运行时检测机制。商业价值在于提升AI供应链的透明度和韧性，产品创新方向包括开发安全配置校验工具或零信任执行环境。
