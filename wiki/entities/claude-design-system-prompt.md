# Claude Design System Prompt

## 中文摘要
Claude设计系统提示词（System Prompt）技术，用于控制AI助手的行为、语气和输出质量。产品经理需关注如何通过精心设计的系统提示词实现产品差异化、提升用户体验、减少有害输出。提示词工程是解锁Claude等大模型商业价值的关键，直接影响对话准确性、安全性和品牌一致性，属于AI产品能力层的基础设施。
