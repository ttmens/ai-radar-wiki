# Show HN: Sentinel – open-source QA agent that reads your code before it clicks

## 中文摘要
Sentinel 是一个开源的 QA 智能体，能够在你点击之前读取代码并自动执行测试。其核心技术在于将代码理解与 UI 交互结合，通过静态分析和动态模拟提前发现缺陷，显著降低回归测试成本。产品创新点在于实现了从“被动测试”到“主动预判”的转变，适合持续集成场景。商业价值体现在开源免费、可私有化部署，能帮助中小企业快速建立自动化测试体系。对于产品经理而言，该工具可减少人为测试疏漏，加速发布周期，尤其适合高迭代频率的 SaaS 产品。
