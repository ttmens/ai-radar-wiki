# Show HN: Agentic Orchestrator, a TUI for long-running coding agents

## 中文摘要
Agentic Orchestrator 是一个为长时间运行的编码智能体设计的终端用户界面（TUI）。它通过图形化的方式管理和监控多个 AI 编码智能体的执行过程，支持任务编排、状态追踪和实时反馈。该工具解决了传统 CLI 中智能体生命周期管理不便的问题，提升了开发者在复杂代码生成或重构场景下的控制力。其商业价值在于降低智能体开发的门槛，适用于自动化代码审查、持续集成等场景，体现了“人机协作”在产品层面的创新。
