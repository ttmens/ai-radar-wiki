# I built a vulnerable app and spent $1,500 seeing if LLMs could hack it

## 中文摘要
该文章作者构建了一个存在漏洞的应用程序，并花费1500美元测试LLM（如GPT系列）能否自主发现并利用这些漏洞进行黑客攻击。这属于LLM在安全领域的红队测试（Red Teaming）能力评估，旨在探索AI自主渗透测试的可行性和成本效益。对于AI产品经理而言，这提示了LLM在自动化安全审计、漏洞挖掘方面的潜在商业价值，可降低传统安全测试的人力成本，但需关注模型可靠性、误报率及伦理边界。产品创新方向包括开发AI安全助手或红队自动化平台。
