# Investigating how prompt politeness affects LLM accuracy (2025)

## 中文摘要
该研究探讨了提示语礼貌程度对大型语言模型（LLM）准确性的影响。实验发现，过度的礼貌或粗鲁可能降低模型表现，而适度礼貌的提示有助于提升输出质量。对AI产品经理而言，这意味着在设计对话系统或用户交互界面时，需要平衡提示的礼貌性以优化模型响应。商业上，可通过调整提示风格提升用户满意度，减少错误率；产品创新上可探索自适应礼貌策略。
