# Show HN: Kastor – Terraform-style specs for AI agents

## 中文摘要
Kastor 是一个开源项目，借鉴 Terraform 的基础设施即代码理念，为 AI Agent 提供声明式的规格定义。它允许产品经理用配置文件描述 Agent 的工具、记忆、行为等，实现版本控制、自动化部署和可复用的 Agent 管理。这种模式降低了 AI Agent 的维护复杂度，提升了团队协作效率，同时通过代码化确保 Agent 行为的可追溯与一致性。对 AI 产品而言，Kastor 意味着将 DevOps 实践引入 Agent 生命周期管理，加速从原型到生产化的过程，并增强系统可靠性。
