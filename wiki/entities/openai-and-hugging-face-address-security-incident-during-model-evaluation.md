# OpenAI and Hugging Face address security incident during model evaluation

## 中文摘要
OpenAI 与 Hugging Face 共同应对模型评估过程中出现的安全事件，凸显了 AI 生态中跨平台安全协作的重要性。该事件可能涉及模型评估环节的漏洞或攻击，双方通过联合响应机制及时修复，保障了模型发布前的安全性。对产品经理而言，需重视模型评估阶段的安全审查，建立与第三方平台的协同应急流程，以降低产品上线风险，增强用户信任。
