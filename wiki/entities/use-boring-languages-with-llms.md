# Use Boring Languages with LLMs

## 中文摘要
本文讨论了在与大语言模型（LLM）交互时，选择使用成熟、稳定的“无聊”编程语言（如Python、Java）而非新兴语言的技术策略。核心观点是：无聊语言拥有更完善的生态、更少的意外行为，便于长期维护和团队协作，从而降低LLM应用开发中的技术风险。对AI产品经理而言，这意味着在构建产品时优先考虑稳定性和可扩展性，避免因语言选择导致项目维护成本激增，同时更易集成现有企业系统，提升产品交付的可靠性。
