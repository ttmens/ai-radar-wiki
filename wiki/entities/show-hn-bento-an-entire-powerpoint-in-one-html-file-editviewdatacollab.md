# Show HN: Bento - An entire PowerPoint in one HTML file (edit+view+data+collab)

## 中文摘要
Bento 是一个创新工具，可将整个 PowerPoint 演示文稿打包为单个 HTML 文件，同时支持编辑、查看、数据存储和协作功能。它消除了传统 PPT 对特定软件的依赖，通过自包含的 HTML 实现跨平台无缝分享与离线可用。技术要点在于前端单文件架构与数据内嵌，商业价值体现在降低分享门槛、提升协作效率，尤其适合需要频繁传递演示内容的团队或教育场景。产品创新在于将复杂应用浓缩为轻量级独立文件，无需安装任何插件即可运行。尽管未直接涉及 AI，但其单文件模式为未来集成 AI 辅助编辑或智能生成内容提供了基础框架。
