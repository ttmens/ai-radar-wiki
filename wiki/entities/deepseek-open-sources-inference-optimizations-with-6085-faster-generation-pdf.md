# DeepSeek open-sources inference optimizations with 60–85% faster generation [pdf]

## 中文摘要
DeepSeek 开源了推理优化方案，实现了 60–85% 的生成速度提升，这对 AI 产品经理意味着显著的性能飞跃。通过加速推理，可降低用户等待时间、提升交互流畅度，同时开源策略降低了模型部署成本，加速产品落地。该技术要点在于优化了生成过程的计算效率，不牺牲质量；商业价值体现在帮助团队快速构建高性能对话/生成应用，并可能推动行业推理优化标准。产品创新方面，开源方式使得中小团队也能直接享受顶尖优化成果，缩短产品迭代周期。
