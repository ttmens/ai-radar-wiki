# I used Claude Code to get a second opinion on my MRI

## 中文摘要
用户使用 Claude Code（Anthropic 的 AI 编程助手）获取自身 MRI 影像的第二诊断意见，展示了大型语言模型从代码生成扩展到医学影像解读场景的产品创新。这一跨领域应用凸显了 AI 在医疗辅助决策中的潜力，通过自然语言交互即可获得专业级分析，降低患者获取第二意见的门槛，对医疗资源普惠化具有商业价值。但需注意模型准确性与监管合规风险，提示产品经理关注垂直领域适配与信任构建。
