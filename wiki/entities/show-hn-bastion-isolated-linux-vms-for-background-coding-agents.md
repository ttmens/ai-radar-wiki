# Show HN: Bastion – isolated Linux VMs for background coding agents

## 中文摘要
Bastion 是一个为后台编码代理提供隔离 Linux 虚拟机的开源项目。它解决了 AI 编码代理在安全执行环境中的关键需求，通过轻量级虚拟机实现代码运行沙箱化，防止恶意操作影响宿主系统。对于 AI 产品经理而言，该工具可降低 AI 辅助编程产品在自动化代码生成、审查、测试等环节的安全风险，适合集成到 CI/CD 或 AI 开发平台中。其技术亮点包括资源隔离、快速启动和 API 友好设计，有助于提升 AI 代理的可靠性与企业级采用率。
