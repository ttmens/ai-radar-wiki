# OpenAI mulls slashing prices as it competes with Anthropic for users

## 中文摘要
OpenAI 正考虑大幅降价以与 Anthropic 争夺用户，显示出 AI 大模型市场竞争加剧，商业模式从技术领先转向价格战。此举可能加速企业客户采用，降低应用门槛，但也考验模型性能与成本平衡。产品经理需关注定价策略对用户留存和生态建设的影响，以及降价是否伴随功能缩减或新商业模式探索。
