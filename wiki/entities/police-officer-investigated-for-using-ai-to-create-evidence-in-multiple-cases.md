# Police officer investigated for using AI to 'create evidence' in multiple cases

## 中文摘要
据报道，一名警察因在多起案件中使用AI“制造证据”而接受调查。这揭示了AI技术被滥用于司法系统的严重风险，尤其是生成虚假证据的能力。对于AI产品经理而言，核心启示在于：必须设计具备可审计性、防篡改机制和来源追踪的AI系统，以防范类似滥用。此外，该事件凸显了AI伦理与合规在产品设计中的关键地位，以及跨部门监管协作的必要性。产品经理需在功能强大与安全可信之间取得平衡，确保输出内容可溯源、可验证，避免成为作恶工具。
