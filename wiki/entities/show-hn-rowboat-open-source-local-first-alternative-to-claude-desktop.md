# Show HN: Rowboat – Open-source, local-first alternative to Claude Desktop

## 中文摘要
Rowboat 是一个开源的、本地优先的桌面 AI 助手，旨在替代 Claude Desktop。它允许用户完全在本地运行 AI 模型，无需网络连接，从而确保数据隐私和安全性。技术要点包括支持多种开源模型（如 Llama、Mistral）、本地知识库集成以及可定制的提示系统。商业价值在于为企业提供低成本、可自托管的 AI 助手解决方案，避免对第三方 API 的依赖。产品创新在于将本地运行、开源定制与类 Claude 的交互体验结合，适合对隐私敏感或需要离线工作的场景。
