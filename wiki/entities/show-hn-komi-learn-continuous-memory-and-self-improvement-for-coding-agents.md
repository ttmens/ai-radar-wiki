# Show HN: Komi-learn – continuous memory and self-improvement for coding agents

## 中文摘要
Komi-learn 是一个为编程代理设计的持续记忆与自我改进工具，通过引入长期上下文和自适应学习机制，使代码代理能够记住之前的交互并不断优化自身行为。该产品面向开发者工具赛道，旨在提升 AI 编程代理的实用性和自主迭代能力，具有明显的产品创新和商业落地点。
