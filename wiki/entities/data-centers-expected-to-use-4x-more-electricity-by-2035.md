# Data centers expected to use 4x more electricity by 2035

## 中文摘要
TechCrunch报道，到2035年数据中心用电量预计将增长4倍，到2033年新建数据中心的年耗电量可能相当于印度当前的总用电量。这对AI产品经理意味着：随着AI应用爆发，基础设施能耗成本将急剧上升，需关注高效模型设计、绿色数据中心趋势及云服务商的能源定价策略。这既是成本风险，也是推动可持续AI创新的商业机会。
