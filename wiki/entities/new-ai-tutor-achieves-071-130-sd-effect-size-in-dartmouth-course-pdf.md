# New AI tutor achieves 0.71-1.30 SD effect size in Dartmouth course [pdf]

## 中文摘要
达特茅斯学院课程中部署的新型AI导师，经评估产生了0.71至1.30标准差的效果量（effect size），远高于传统教学干预的平均效果。这表明该AI系统能显著提升学生学习成效，尤其在个性化辅导、即时反馈和自适应学习路径方面展现强大能力。对AI产品经理而言，该案例验证了AI在教育领域的高效性，为开发智能辅导工具提供了实证基础。商业价值在于可复制到K-12、高等教育及职业培训市场，产品创新点在于量化学习效果并实现大规模个性化教学。
