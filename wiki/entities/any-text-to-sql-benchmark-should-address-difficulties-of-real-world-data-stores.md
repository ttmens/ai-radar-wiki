# Any text-to-SQL benchmark should address difficulties of real-world data stores

## 中文摘要
当前Text-to-SQL基准测试未能充分反映真实数据仓库的复杂性，如不规则列名、缺失值、多表关联和动态schema等实际困难。产品经理应关注构建贴近业务场景的评测标准，避免模型在学术数据集上表现优异而落地时效果不佳。该分析强调了评测体系对驱动模型优化和产品可靠性的关键作用。
