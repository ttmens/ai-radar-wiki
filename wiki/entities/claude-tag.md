# Claude Tag

## 中文摘要
Claude Tag 是 Anthropic 为 Claude 推出的标签功能，允许用户为对话添加自定义标签，便于检索、分类和长期记忆管理。该功能提升了 AI 助手的组织能力，通过标签实现上下文复用和跨会话知识沉淀，对构建个性化工作流和知识库有商业价值。技术要点在于标签与对话历史的高效关联及语义检索优化。
