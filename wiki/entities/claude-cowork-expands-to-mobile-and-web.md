# Claude Cowork expands to mobile and web

## 中文摘要
Claude Cowork 扩展至移动端和网页端，支持用户跨设备无缝协作：在桌面启动任务，手机端实时查看进度，即使关闭笔记本也能在任意设备获取最终输出。该能力提升了AI任务管理的异步性和连续性，解决了传统AI工具需保持会话活跃的痛点，尤其适合移动办公场景。商业价值在于降低用户切换成本，增强产品粘性，推动“随时随地的AI协作者”产品定位。
