# Google&#8217;s AI Studio now lets anyone build Android apps in minutes

## 中文摘要
Google 推出基于 Web 的 AI Studio 工具，允许用户通过自然语言描述在几分钟内生成原生 Android 应用。该工具利用大语言模型自动生成 UI 布局、逻辑代码和资源文件，无需手动编写代码，显著降低移动应用开发门槛。商业价值在于赋能非技术用户快速验证创意，加速原型迭代，同时可能改变应用开发流程，使 AI 成为核心生产力工具。产品创新体现在将 AI 能力深度集成到 Android 开发环境，支持实时预览与修改，展示生成式 AI 从文本到完整应用的跨越。
