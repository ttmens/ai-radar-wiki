# Anthropic releases Opus 4.8 with new &#8216;dynamic workflow&#8217; tool

## 中文摘要
Anthropic 发布 Opus 4.8 模型，新增“动态工作流”工具，用于协调多个子代理群协同完成任务。该功能支持动态任务分配、上下文共享和结果汇总，使开发者能构建更复杂、自适应的 AI 工作流。商业价值在于降低多智能体系统的开发门槛，提升企业级自动化效率；产品创新体现在从单一模型响应转向可编排的代理协作模式，为 AI 应用带来更高灵活性和可扩展性。
