# If LLMs Have Human-Like Attributes, Then So Does Age of Empires II

## 中文摘要
本文通过类比《帝国时代II》中游戏AI的决策逻辑，探讨了大语言模型（LLM）是否真正具备类人属性。作者认为，LLM的某些能力（如规划、推理）与经典游戏AI的规则引擎和状态机有相似之处，并非真正的人类认知，而是对模式的学习和模拟。对AI产品经理的启示是：在将LLM应用于策略、模拟或游戏类产品时，需警惕过度拟人化带来的预期偏差，应更关注其模式匹配与实际场景的适配性，避免高估其自主决策能力。
