# Claude Code uses Bun written in Rust now

## 中文摘要
Claude Code（Anthropic 推出的 AI 编程助手）现在改用 Bun（基于 Rust 编写的高性能 JavaScript 运行时）作为其底层运行环境。这一技术栈更迭意味着 Claude Code 可能获得更快的启动速度、更低的内存占用以及更稳定的执行性能，从而提升开发者的实时交互体验。对于产品经理而言，此举体现了通过底层基础设施优化来强化核心能力的思路：在不改变功能逻辑的前提下，借助更高效的运行时降低成本、提升响应速度，增强产品在 AI 编程助手市场的竞争力。
