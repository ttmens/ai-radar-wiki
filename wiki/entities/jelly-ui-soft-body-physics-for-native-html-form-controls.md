# Jelly UI: Soft-body physics for native HTML form controls

## 中文摘要
Jelly UI 项目通过软体物理模拟，为原生HTML表单控件（如按钮、滑块、复选框）添加了富有弹性和动态效果的交互反馈。技术要点包括基于物理引擎（如Cannon.js）实时变形与碰撞响应，无需额外库即可增强用户体验。商业价值体现在提升Web表单的视觉吸引力和操作直觉性，适用于游戏化、教育及创意工具等场景，降低用户认知负荷。产品创新在于将游戏中的物理交互模式引入标准UI组件，使静态控件变得生动、可预测，为AI驱动的动态界面提供了新的交互范式。
