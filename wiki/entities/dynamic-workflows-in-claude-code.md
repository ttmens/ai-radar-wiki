# Dynamic Workflows in Claude Code

## 中文摘要
Claude Code 中的动态工作流（Dynamic Workflows）允许 AI 在编码过程中实时调整和生成任务序列，提升开发者效率。该模式以 Claude 为核心，根据上下文自动拆解复杂编程任务并动态协调子步骤，减少手动切换频率。产品创新在于将静态指令流转化为自适应流程，适用于持续集成、代码审查等场景。商业上可降低研发成本，加速交付。
