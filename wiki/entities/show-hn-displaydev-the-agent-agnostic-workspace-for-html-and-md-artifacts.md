# Show HN: Display.dev – the agent-agnostic workspace for HTML and .md artifacts

## 中文摘要
Display.dev 是一个与具体 AI agent 无关的工作空间，专门用于展示和协作 HTML 及 Markdown 格式的工件（artifacts）。它解决了不同 AI agent 生成内容格式不统一、难以集中管理的问题，为产品经理提供了一个统一的视图来查看、对比和迭代 AI 输出。该工具不绑定特定 agent，支持灵活集成，有助于降低多 agent 场景下的工具切换成本，提升团队协作效率。其核心价值在于通过标准化工件展示，促进 AI 驱动的工作流标准化和可复用性。
