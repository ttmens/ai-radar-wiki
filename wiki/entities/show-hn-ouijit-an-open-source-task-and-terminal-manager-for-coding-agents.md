# Show HN: Ouijit, an open-source task and terminal manager for coding agents

## 中文摘要
Ouijit 是一个面向编码代理的开源任务和终端管理器，旨在为 AI 代理提供统一的任务调度与命令行交互能力。其核心价值在于通过结构化任务管理和终端会话跟踪，提升编码代理的执行效率与可观测性。产品创新体现在将传统开发者工具（任务板、终端模拟器）适配至 AI 工作流，支持代理自主切换上下文、记录操作历史，从而减少人工干预。对于 AI 产品经理而言，该工具代表了“代理工作台”模式的早期探索，可能成为未来 AI Agent 开发基础设施的关键组件。
