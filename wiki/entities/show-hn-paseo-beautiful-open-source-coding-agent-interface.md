# Show HN: Paseo – Beautiful open-source coding agent interface

## 中文摘要
Paseo 是一款开源且界面美观的编码代理接口，旨在为开发者提供优雅的 AI 编程辅助体验。通过集成大语言模型，它能够理解自然语言指令并生成代码片段，支持多种编程语言。作为一款开源项目，Paseo 降低了企业使用 AI 编程助手的成本，同时允许社区贡献自定义功能，促进生态发展。其视觉设计注重用户体验，减少使用摩擦，适合嵌入到现有开发流程中。商业价值体现在对商业 Copilot 产品的去中心化替代，推动 AI 开发工具民主化。
