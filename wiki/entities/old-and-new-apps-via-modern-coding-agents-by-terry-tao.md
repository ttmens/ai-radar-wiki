# Old and new apps, via modern coding agents by Terry Tao

## 中文摘要
著名数学家陶哲轩（Terry Tao）在HN上探讨了利用现代编码代理（AI coding agents）开发新旧应用的方式。技术要点包括：AI代理能够理解自然语言需求并自动生成完整代码，显著提升开发效率；可重构传统应用并快速迭代新原型。商业价值在于降低开发门槛和成本，加速产品上市。产品创新体现在非程序员也能通过对话式交互创建应用。
