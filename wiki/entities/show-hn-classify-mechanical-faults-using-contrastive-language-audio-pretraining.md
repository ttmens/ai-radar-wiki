# Show HN: Classify mechanical faults using Contrastive Language-Audio Pretraining

## 中文摘要
该技术利用对比语言-音频预训练（CLAP）模型实现机械故障分类，通过将设备运行音频与故障描述文本对齐，无需大量标注数据即可识别异常。核心在于将多模态对比学习从图像-文本扩展到音频-文本领域，降低工业场景中数据采集成本。商业价值体现在预测性维护、减少停机时间和维修成本，产品创新在于零样本故障诊断能力，适配多种机械类型。
