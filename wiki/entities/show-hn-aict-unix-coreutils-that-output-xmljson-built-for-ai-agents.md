# Show HN: Aict – Unix coreutils that output XML/JSON, built for AI agents

## 中文摘要
Aict 是一个面向 AI 代理的 Unix 核心工具集合，将标准 Unix 命令输出转换为 XML 或 JSON 格式。它解决了传统命令行输出不易被 AI 解析的问题，使得 AI agent 能够直接获取结构化数据，无需额外解析步骤。该工具降低了 AI 系统与 Linux 环境集成的门槛，提升了自动化脚本和智能体的效率。对于产品经理而言，这代表了一种基础设施层的创新，可加速 AI 在企业级 Unix 系统中的应用部署。
