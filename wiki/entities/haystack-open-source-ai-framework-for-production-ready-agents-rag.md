# Haystack: Open-Source AI Framework for Production Ready Agents, RAG

## 中文摘要
Haystack 是一个开源 AI 框架，专注于构建生产级 Agent 和 RAG（检索增强生成）应用。它提供模块化组件，支持多种 LLM 集成与灵活管道设计，降低了开发门槛，加速企业级 AI 产品的落地。产品经理可借助 Haystack 快速验证 RAG 或 Agent 模式，实现知识问答、文档分析等场景，同时保持系统可维护性与可扩展性。
