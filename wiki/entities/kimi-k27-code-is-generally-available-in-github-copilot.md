# Kimi K2.7 Code is generally available in GitHub Copilot

## 中文摘要
Kimi（Moonshot AI）的代码能力升级版K2.7现已集成至GitHub Copilot，开发者可直接在IDE中调用该模型进行代码补全和生成。此举标志着国产大模型首次深度嵌入全球最流行的开发工具链，显著降低了使用门槛，同时验证了Kimi在代码理解与生成上的技术突破。对AI产品经理而言，这是“模型+平台”生态合作模式的经典案例，也预示着未来AI编码助手将更加多模型化、平台开放化。
