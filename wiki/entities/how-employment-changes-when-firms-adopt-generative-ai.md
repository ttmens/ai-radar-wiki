# How employment changes when firms adopt generative AI

## 中文摘要
该研究聚焦企业采用生成式AI后对就业结构的影响，揭示自动化替代与岗位增强并存的现象。技术要点包括AI在任务级替代的边界、新协作岗位的涌现以及劳动力再分配趋势。商业价值方面，企业需平衡效率提升与员工转型成本，产品创新方向在于设计人机协同工具和再培训平台。AI产品经理应关注模型能力边界对工作流程的重塑，以及如何通过产品设计降低采纳阻力，实现可持续的AI部署。
