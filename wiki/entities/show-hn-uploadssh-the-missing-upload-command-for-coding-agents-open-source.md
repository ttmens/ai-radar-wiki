# Show HN: Uploads.sh – the missing upload command for coding agents (open-source)

## 中文摘要
Uploads.sh 是一个开源命令行工具，专为编码代理（如 AI 编程助手）设计，提供统一的上传命令，方便代理将文件上传到远端（如云存储、服务器）。它解决了现有代理缺乏标准上传接口的问题，通过简单的一行命令实现文件传输，支持多种目标并具有安全认证功能。该工具填补了 AI 编程工作流中的空白，提升开发者与代码代理协作效率，属于开发者生态中的基础设施创新。
