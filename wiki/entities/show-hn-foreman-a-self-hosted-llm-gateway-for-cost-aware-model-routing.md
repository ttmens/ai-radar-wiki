# Show HN: Foreman, a self-hosted LLM gateway for cost aware model routing

## 中文摘要
Foreman 是一款自托管的 LLM 网关，专注于成本感知的模型路由。它允许开发者灵活地在多个大语言模型之间智能分配请求，根据实时成本、延迟和性能指标自动选择最优模型，从而优化 AI 应用的运营成本与响应质量。该工具特别适合需要控制 LLM 开支的中大型企业，支持私有化部署以保障数据安全。作为产品创新，它降低了多模型管理的复杂度，使产品经理能够在不依赖第三方服务的情况下实现精细化的模型调度策略，提升 ROI。
