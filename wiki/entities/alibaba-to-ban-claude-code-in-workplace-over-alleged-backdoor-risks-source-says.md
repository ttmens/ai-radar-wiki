# Alibaba to ban Claude Code in workplace over alleged backdoor risks, source says

## 中文摘要
据报道，阿里巴巴因担忧后门风险，计划在工作场所禁止使用Claude Code（Anthropic的AI编码助手）。这一决策凸显了企业级AI工具面临的安全性与合规性挑战，尤其是当AI模型可能通过代码生成引入隐蔽漏洞时。对于AI产品经理而言，这意味着在推广AI编码助手等产品时，必须优先考虑数据安全、模型审计和供应链风险评估。该事件也反映出大型企业在采用外部AI工具时的谨慎态度，可能推动更多企业自研或选择经过严格安全审查的AI解决方案，从而影响市场格局。
