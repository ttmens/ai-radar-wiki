# Show HN: A Pipeline for Making 10-minute AI Movies with Claude Code and Seedance

## 中文摘要
该方案利用 Claude Code 的代码生成能力和 Seedance 的视频生成能力，构建了一条完整的端到端流水线，用于制作 10 分钟长度的 AI 电影。技术要点包括将剧本拆解为场景、自动生成镜头脚本、调用多模态模型生成视频片段并拼接。商业上显著降低电影制作门槛，适合快速产出短视频或概念预告片。产品创新在于将代码驱动的工作流与视频生成引擎深度集成，实现自动化叙事。
