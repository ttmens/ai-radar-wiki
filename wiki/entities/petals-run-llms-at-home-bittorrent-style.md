# Petals: Run LLMs at home, BitTorrent-style

## 中文摘要
Petals是一个开源项目，允许用户通过点对点网络（类似BitTorrent）在家中运行大型语言模型（LLM）。它将模型划分为多个“叶片”，由社区中的不同设备共同托管和计算，从而实现低成本的分布式推理。对于产品经理而言，这意味着无需依赖昂贵的数据中心或云服务，即可利用闲置的个人设备运行先进的LLM，大幅降低AI应用部署成本。同时，这种模式支持模型微调和推理的并行化，增强了AI的可访问性和隐私保护。商业价值在于催生去中心化的AI服务生态，以及边缘计算与社区协作的新产品形态。
