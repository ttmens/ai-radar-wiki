# GPT‑NL: a sovereign language model for the Netherlands

## 中文摘要
GPT-NL是荷兰开发的主权语言模型，旨在满足该国对数据主权、语言文化和法规合规的特定需求。技术要点包括：基于本国数据训练、适配荷兰语及低地德语变体、符合欧盟AI法案和GDPR要求；商业价值在于为政府、医疗、法律等敏感行业提供安全可控的本地化AI能力，减少对境外模型的依赖；产品创新体现为模块化架构和区域专属优化，支持定制化部署。该模型强调透明度和可解释性，可赋能公共服务、金融等场景。
