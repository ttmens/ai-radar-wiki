# Show HN: Adrafinil – keep a lid-closed Mac awake only while agents work

## 中文摘要
Adrafinil 是一个针对 Mac 用户的开源工具，允许在合盖状态下保持系统唤醒，仅当 AI 代理（如本地 Agent 或 LLM 任务）运行时生效。它通过智能管理电源设置，避免笔记本休眠导致的任务中断，从而提升本地 AI 代理的持续运行效率和可靠性。该工具适用于需要长期后台运行 AI 任务的产品，如个人助理、自动化工作流或边缘计算场景。产品创新在于精准控制唤醒时机，既节省能耗又保证 Agent 可用性。对于产品经理，这降低了本地 AI 部署的运维门槛，推动了“本地优先 AI”模式的落地。
