# NSA using Anthropic's Mythos for cyber attacks

## 中文摘要
美国国家安全局（NSA）利用Anthropic开发的'神话'（Mythos）AI系统实施网络攻击，表明先进AI模型正被应用于国家级黑客行动。Mythos可能融合了语言模型与自动化攻击链设计能力，能生成高度隐蔽的恶意代码或社交工程内容。这一事件凸显了AI在网络安全领域的双刃剑效应：既可用于防御，也可被武器化。对产品经理而言，需关注AI系统的安全审计与滥用防范，以及如何设计内置伦理约束的功能机制。
