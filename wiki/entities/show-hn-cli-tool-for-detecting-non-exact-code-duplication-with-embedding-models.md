# Show HN: CLI tool for detecting non-exact code duplication with embedding models

## 中文摘要
该工具是一个命令行界面（CLI）应用，利用嵌入模型（如CodeBERT等）检测代码库中非精确的重复代码片段。与传统的基于语法或文本的精确克隆检测不同，该方法通过语义嵌入计算代码片段的相似度，能识别出逻辑相同但实现细节不同的代码克隆，有助于开发者发现潜在的技术债务、减少冗余、提升代码可维护性。产品创新在于将自然语言处理中的嵌入技术应用于代码分析，提供轻量级本地工具，无需依赖云服务，适合集成到CI/CD或开发工作流中，具有显著的工程效率提升价值。
