# Write code like a human will maintain it

## 中文摘要
本文讨论如何编写具有高度可维护性的代码，强调“像人类会维护它一样写代码”。对于AI产品经理而言，这意味着AI生成的代码不仅要功能正确，更要遵循人类可读、可理解、易维护的规范，降低后续维护成本。该理念可指导AI辅助编码工具的设计，提升代码质量和团队协作效率，间接影响AI产品的开发周期和长期稳定性。核心在于将人类维护习惯融入AI编码逻辑。
