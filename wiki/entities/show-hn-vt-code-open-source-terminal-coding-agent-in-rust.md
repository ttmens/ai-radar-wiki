# Show HN: VT Code – open-source terminal coding agent in Rust

## 中文摘要
VT Code 是一个开源的终端编码代理，使用 Rust 语言实现，专注于在命令行环境中为开发者提供 AI 辅助编程能力。它支持代码生成、理解和编辑，通过终端原生交互降低使用门槛，适合习惯命令行的开发者。技术亮点在于 Rust 的高性能与低资源占用，可集成多种大语言模型。产品创新点在于将 AI 编码代理从传统 IDE 插件形态迁移到纯终端，提升了自动化脚本和远程开发场景的灵活性。商业价值上，开源模式促进社区协作，有望成为开发者生态中的重要工具。
