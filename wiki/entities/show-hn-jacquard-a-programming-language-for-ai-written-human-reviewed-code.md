# Show HN: Jacquard, a programming language for AI-written, human-reviewed code

## 中文摘要
Jacquard 是一种专为 AI 编写、人类审核代码而设计的编程语言。它旨在解决 AI 生成代码可靠性和可控性问题，通过语言层面的约束和标注机制，让开发者能清晰区分 AI 生成的代码与人工编写部分，并强化代码可审查性。该语言可能内建代码审查流程支持，降低 AI 代码的落地风险。对产品经理而言，这代表了 AI 辅助编程从“生成-检查”到“生成-审核-集成”的深度整合，有望提升开发团队效率与代码质量，尤其在安全敏感或业务关键系统中具有商业价值。
