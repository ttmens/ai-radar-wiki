# Show HN: Crespo – Tree-sitter AST blueprints instead of raw code for LLMs

## 中文摘要
Crespo 项目提出用 Tree-sitter 生成的抽象语法树（AST）蓝图替代原始代码作为 LLM 的输入，旨在提升模型对代码结构和语义的理解，减少幻觉与错误。该方案通过结构化表示将代码逻辑拆解为更清晰的层级，有利于 LLM 执行代码生成、补全、翻译等任务。对产品经理而言，这代表一种“代码预处理”创新，有望降低 AI 编程助手的调优成本，提升输出质量与开发效率，可能成为下一代代码智能工具的关键基础设施。
