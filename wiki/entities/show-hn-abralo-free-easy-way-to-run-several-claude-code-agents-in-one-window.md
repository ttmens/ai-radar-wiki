# Show HN: Abralo – Free, easy way to run several Claude Code agents in one window

## 中文摘要
Abralo 是一款免费工具，允许用户在一个窗口中同时运行多个 Claude Code 代理。它简化了多代理协作的配置与监控流程，使开发人员能够并行处理任务、对比不同代理输出或进行协同调试。产品创新在于零成本、可视化界面以及低上手门槛，直接提升了 Claude Code 在团队协作和复杂工作流中的复用效率。对于 AI 产品经理而言，这代表了一种降低多代理系统试错成本、加速原型验证的实用方案，尤其适合需要同时管理多个 AI 编程助手的场景。
