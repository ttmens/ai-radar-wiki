# SpaceXAI releases Grok 4.5, which Elon describes as an &#8216;Opus-class model&#8217;

## 中文摘要
xAI（标题中误写为SpaceXAI）发布了Grok 4.5版本，Elon Musk将其描述为‘Opus-class model’，意在提供比现有强大AI模型更便宜、更高效的替代方案。该模型在保持高水平推理能力的同时，显著降低了计算成本和能耗，使得中小企业和开发者能够以更低门槛接入先进AI能力。从产品创新角度看，Grok 4.5强调‘效率优先’的路线，可能推动AI模型从单纯追求参数量转向实用性优化。商业上，这加剧了与OpenAI、Google等厂商的竞争，为AI产品经理提供了成本更优的基础模型选择，尤其适合对延迟和预算敏感的实时应用场景。
