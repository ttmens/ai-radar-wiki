# DSLs Enable Reliable Use of LLMs

## 中文摘要
领域特定语言（DSLs）通过为 LLM 提供精确的语法和约束，显著提升其输出的可靠性和一致性。对产品经理而言，DSL 能降低幻觉风险、增强可控性，尤其适合金融、医疗等对准确性要求高的场景。商业上，它为企业安全落地 LLM 提供了桥梁，无需依赖昂贵的 prompt 调试。产品创新方面，可设计面向非技术用户的 DSL 接口，让业务专家直接定义逻辑。
