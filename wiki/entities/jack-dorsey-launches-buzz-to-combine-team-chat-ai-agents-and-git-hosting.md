# Jack Dorsey launches Buzz to combine team chat, AI agents and Git hosting

## 中文摘要
Jack Dorsey 推出 Buzz，一个融合团队聊天、AI 代理和 Git 托管的协作平台。该产品旨在简化开发工作流，通过在聊天界面中嵌入 AI 代理来辅助代码审查、任务管理和自动化流程。同时，内置 Git 托管功能使团队无需切换工具即可管理代码仓库。对于 AI 产品经理而言，Buzz 代表了将 AI 代理深度融入日常协作工具的新模式，可能重塑开发团队的协作方式，并降低从沟通到部署的摩擦。
