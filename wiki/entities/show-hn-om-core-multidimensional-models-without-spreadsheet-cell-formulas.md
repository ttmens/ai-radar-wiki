# Show HN: OM Core – multidimensional models without spreadsheet cell formulas

## 中文摘要
OM Core 是一个无需电子表格公式即可构建多维数据模型的新工具，旨在简化复杂数据分析流程。它通过直观的界面替代传统单元格公式，降低数据处理门槛，适合业务分析师和产品经理快速建模。其商业价值在于提升数据驱动决策效率，减少对技术团队的依赖，可能重塑数据分析工作流。产品创新在于将多维模型的可视化与免公式操作结合，实现即拖即用。
