# Anna's Archive Hit with $19.5M Default Judgment and Global Domain Takedown Order

## 中文摘要
Anna's Archive 因未经授权大规模抓取和分发受版权保护的资料，被美国法院判决支付1950万美元赔偿金，并面临全球域名下架命令。这一事件对AI产品经理的启示在于：训练数据的版权合规性已成为重大法律风险，尤其当使用爬虫收集公开数据进行模型训练时。该判决可能影响数据获取策略，推动行业采用更严格的版权审查和许可获取流程，也可能促使更多企业转向合成数据或明确授权数据源。产品经理需关注数据供应链的法律风险，避免因训练数据侵权导致产品下架或巨额赔偿。
