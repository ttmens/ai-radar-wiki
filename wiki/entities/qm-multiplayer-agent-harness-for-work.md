# qm – Multiplayer agent harness for work

## 中文摘要
qm 是一个面向工作场景的多智能体协作框架，强调通过多人参与的方式协调多个 AI 代理共同完成任务。其核心价值在于将智能体从单点工具扩展为可协同工作的团队，提升复杂工作流的自动化与效率。该工具可能提供任务分配、状态同步和结果聚合等机制，适合企业级多角色协作场景，是智能体从个体走向组织化的重要探索，具有较高的产品化潜力。
