# Show HN: Tiny-vLLM – high performance LLM inference engine in C++ and CUDA

## 中文摘要
Tiny-vLLM 是一个用 C++ 和 CUDA 实现的高性能 LLM 推理引擎，专注于提升推理速度和降低资源消耗。对产品经理而言，其技术亮点在于极低的延迟和高效的 GPU 利用，可显著降低云推理成本或支持本地 / 边缘部署。商业价值体现在让中小企业也能负担高质量 AI 服务，产品创新点在于轻量化设计，易于集成到现有系统。该引擎适合对实时性要求高的场景，如聊天机器人、代码助手等。
