# Show HN: Codebase Posters – turn any Git repo into generative poster art

## 中文摘要
Codebase Posters 是一款将任意 Git 仓库转化为生成式海报艺术的产品。它利用 AI 视觉模型，解析代码仓库的结构、文件树、提交历史等特征，自动生成抽象或风格化的视觉艺术品，使开发者能够以艺术形式展示其代码项目。技术核心包括 Git 数据解析与生成式 AI 的结合，商业价值体现在开发者社区个性化周边、技术博客封面、公司文化墙等场景。产品创新在于将枯燥的代码库转化为可收藏、可分享的审美作品，降低了 AI 图像生成的门槛。
