# LLM Honeypot

## 中文摘要
LLM Honeypot 概念利用大语言模型作为“蜜罐”，通过模拟对话或API接口诱捕恶意攻击者，收集其对AI系统的攻击手法与漏洞利用模式。该技术可帮助企业提前发现LLM应用中的提示注入、数据泄露等安全风险，为构建更安全的AI产品提供测试环境。商业价值体现在降低安全合规成本、提升客户信任，同时为安全厂商提供新型防护工具。产品创新在于将传统蜜罐与生成式AI结合，实时生成动态诱饵内容，增强欺骗效果。
