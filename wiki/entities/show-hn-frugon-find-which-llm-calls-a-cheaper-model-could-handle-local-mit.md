# Show HN: Frugon – Find which LLM calls a cheaper model could handle (local, MIT)

## 中文摘要
Frugon 是一个本地运行的开源工具（MIT协议），能够自动分析你的 LLM 调用日志，识别哪些请求可以使用更便宜的模型处理。它通过评估任务复杂度与模型能力匹配度，提出成本优化建议，帮助企业降低 API 调用费用。产品创新在于完全本地化、无数据外泄，且无需修改现有代码即可集成。技术要点包括模型路由逻辑和开销评估算法。对 AI 产品经理而言，Frugon 提供了直观的成本管控手段，尤其在多模型部署场景中价值显著。
