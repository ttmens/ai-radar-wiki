# Show HN: Mira – Open-source and self-hosted AI code reviewer

## 中文摘要
Mira 是一款开源且支持自托管的 AI 代码审查工具，旨在帮助企业私有化部署 AI 审阅能力，保障代码数据安全。产品基于 AI 模型自动分析代码提交，提供错误检测、风格建议、最佳实践提醒等功能，可与主流版本控制系统（如 Git）集成。其商业价值在于降低 SaaS 订阅成本，满足金融、医疗等对数据合规要求严格的场景。产品创新体现在完全开源的架构、灵活的本地部署、以及对自定义审查规则的开放支持，适合希望深度定制开发流程的团队。
