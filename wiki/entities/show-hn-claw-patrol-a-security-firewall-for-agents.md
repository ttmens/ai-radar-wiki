# Show HN: Claw Patrol, a security firewall for agents

## 中文摘要
Claw Patrol 是一款专为 AI 代理设计的安全防火墙，通过实时监控和拦截恶意指令、数据泄露等风险，保障代理在复杂环境中的安全运行。它为产品经理提供了关键的 Agent 安全基础设施，有助于提升企业级 AI 应用的信任度与合规性，是代理生态中不可或缺的安全组件。
