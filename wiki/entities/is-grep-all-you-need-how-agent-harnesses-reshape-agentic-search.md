# Is Grep All You Need? How Agent Harnesses Reshape Agentic Search

## 中文摘要
本文探讨了“Grep”作为AI Agent核心工具的可行性，提出Agent Harnesses（代理工具链）如何重塑代理式搜索（Agentic Search）。核心观点是：像grep这样简单高效的文本搜索模式，结合AI Agent的决策能力，可以形成一种轻量级、模块化的搜索范式，避免依赖庞大模型。产品创新在于降低搜索延迟和成本，提升可解释性；商业价值体现在企业级搜索、文档检索场景的快速落地；技术要点强调“模式即搜索”（Pattern as Search）的设计理念。
