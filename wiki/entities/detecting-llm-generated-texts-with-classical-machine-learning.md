# Detecting LLM-Generated Texts with “Classical” Machine Learning

## 中文摘要
本文探讨了如何利用经典机器学习方法（如逻辑回归、随机森林、支持向量机等）来检测由大语言模型生成的文本。这类方法通常基于统计特征、词汇模式、困惑度等指标，与当前流行的神经网络检测器相比，具有训练成本低、可解释性强、泛化能力良好等优点。对于AI产品经理而言，该技术可嵌入内容审核、学术诚信检测、假新闻识别等场景，降低对大量标注数据的依赖，并能快速部署到现有系统中。同时，经典模型的可解释性有助于合规审计和用户信任建设，是一种值得关注的轻量级检测方案。
