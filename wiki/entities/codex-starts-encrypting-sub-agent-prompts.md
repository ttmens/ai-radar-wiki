# Codex starts encrypting sub-agent prompts

## 中文摘要
Codex 项目开始对子代理的提示（prompts）进行加密，旨在增强多AI代理系统中的数据隐私与安全性。这一举措通过加密子代理之间的通信内容，防止敏感信息泄露，为构建更安全的协作式AI应用奠定基础。对产品经理而言，这意味着在设计涉及多个AI代理协同工作的产品时，可以引入加密机制来满足企业级安全合规需求，同时提升用户信任。该技术有望推动金融、医疗等高度隐私敏感领域的AI代理应用落地。
