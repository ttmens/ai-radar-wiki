# Claude Code Is Steganographically Marking Requests

## 中文摘要
Claude Code 通过隐写术在请求中嵌入隐蔽标记，以实现请求溯源或内容保护。此举提升代码助手的安全性与可信度，但可能引发用户对隐私透明的关注。该技术为 AI 产品增加了版权追踪能力，是安全合规的创新方向。
