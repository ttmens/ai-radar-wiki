# Show HN: Recall – Local project memory for Claude Code

## 中文摘要
Recall 是一个为 Claude Code 提供本地项目记忆的工具，通过在本地持久化存储编码会话的上下文，解决了 AI 编码助手在长期任务中容易遗忘前文的问题。该工具无需依赖云端，保护数据隐私，同时支持跨会话记忆，让开发者能在多个编码任务中保持连贯的上下文。对于 AI 产品经理，这展示了如何通过本地化存储增强大模型在特定场景下的实用性和用户粘性，尤其适合需要长期上下文支持的开发工具，潜在提升编码效率 10%-30%。
