# Show HN: PMB – local memory for coding agents that shows if it is used

## 中文摘要
PMB（Prompt Memory Bank）是一个为编码代理设计的本地内存系统，能够显式记录内存是否被使用，提升透明度和可观测性。其核心创新在于通过本地存储和可见性反馈，解决AI编程助手在长期对话中上下文丢失或误用的问题，使开发者可追踪内存调用情况。这对构建可信赖的AI编码工具具有产品价值，尤其适合需要精细控制上下文的IDE插件场景。
