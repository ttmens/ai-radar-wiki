# Prevent cognitive debt by manually retyping LLM-generated code

## 中文摘要
该内容讨论一种反直觉的实践：开发者手动重新输入 LLM 生成的代码，而非直接复制粘贴，以降低认知债务。核心逻辑是，通过逐字敲击代码，开发者被迫逐步理解每一行逻辑，建立心智模型，避免未来维护时的理解断层。对 AI 产品经理的启示是：代码生成工具不应只追求生成效率，还需关注开发者长期的知识内化与代码可维护性。这提示产品可设计“理解增强”机制，如分步展示、强制审查或交互式重构，平衡短期效率与长期认知负担，提升开发者的可持续生产力。
