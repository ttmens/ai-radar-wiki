# Show HN: Oak – Git alternative designed for agents

## 中文摘要
Oak 是一款专为 AI 代理设计的 Git 替代品，旨在解决传统版本控制系统在代理协作中的痛点，如冲突处理、长时间运行任务的版本管理。它可能引入智能合并、并发控制、持久化历史等功能，使多代理可像团队一样协同编码。对 AI 产品经理而言，该工具可降低代理开发与部署的版本管理成本，提升迭代效率，是 AI 原生基础设施的创新探索。
