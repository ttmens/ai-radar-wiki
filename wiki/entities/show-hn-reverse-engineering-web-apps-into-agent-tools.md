# Show HN: Reverse-engineering web apps into agent tools

## 中文摘要
该项目展示了一种逆向工程方法，将现有Web应用自动转化为AI Agent可调用的工具。通过解析网页结构、API接口和交互逻辑，无需原始代码即可为Agent生成功能接口。这显著降低了构建Agent工具集的门槛，使产品经理能快速整合SaaS、内部系统等成熟Web服务。技术要点包括自动化抓取、意图映射和工具封装；商业价值在于加速AI产品开发周期，利用已有应用生态；产品创新体现为“零代码”Agent工具生成模式。
