# Show HN: Zot – Yet another coding agent harness

## 中文摘要
Zot 是一个新型编码代理工具框架（harness），专注于简化 AI 编码助手的构建流程。它可能提供模块化设计、任务编排和集成能力，允许开发者快速搭建定制化的代码生成 agent。该工具借鉴了类似 Copilot 的模式，但强调灵活性和可扩展性，旨在降低编码 agent 的开发门槛。对于 AI 产品经理，这意味着可以更高效地实验和部署编码辅助功能，提升开发团队生产力。其产品创新在于将 agent 的构建过程标准化为可复用的 harness 模式。
