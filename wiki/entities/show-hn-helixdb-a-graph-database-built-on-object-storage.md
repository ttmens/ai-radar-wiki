# Show HN: HelixDB – A graph database built on object storage

## 中文摘要
HelixDB 是一款基于对象存储构建的图数据库，将图数据库的灵活查询能力与云原生对象存储的弹性、低成本、高扩展性相结合。面向AI产品经理，其核心价值在于降低图数据库运维复杂度，支持大规模知识图谱和关系推理场景，适合需要动态元数据管理的AI应用。产品创新体现在去中心化存储架构，消除了传统图数据库对本地磁盘的依赖，实现近乎无限的存储扩展。
