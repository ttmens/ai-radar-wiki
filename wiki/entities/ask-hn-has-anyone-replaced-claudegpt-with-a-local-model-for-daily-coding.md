# Ask HN: Has anyone replaced Claude/GPT with a local model for daily coding?

## 中文摘要
该讨论在Hacker News上发起，核心问题是开发者是否已成功用本地大模型（如Code Llama等）替代Claude或GPT进行日常编程。关键考量包括：本地模型在代码生成、补全和调试上的能力是否媲美云端模型；隐私与数据安全优势（代码不离开本地）；成本控制（无需API订阅费）；以及硬件需求（GPU/内存瓶颈）。产品经理需关注本地模型与云端模型的性能差距、部署难度和用户体验折中，以决定产品策略（例如是否提供本地优先的AI编程助手）。
