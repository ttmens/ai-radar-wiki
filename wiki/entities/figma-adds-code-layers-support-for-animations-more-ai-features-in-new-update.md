# Figma adds code layers, support for animations, more AI features in new update

## 中文摘要
Figma 最新更新新增了代码层、动效和着色器支持，并引入 AI 功能以创建自定义插件。AI 技术使得设计师能通过自然语言快速生成适配设计稿的代码片段、动画效果及插件逻辑，显著降低从设计到开发的手动转化成本。该更新强化了 Figma 作为设计系统核心工具的生态地位，为产品经理提供了更高效的原型交付与团队协作路径。商业价值体现在缩短设计-开发周期、提升交付质量，同时通过插件生态扩大平台影响力。产品创新在于将 AI 能力深度嵌入设计工具的核心工作流，而非仅作为附加功能。
