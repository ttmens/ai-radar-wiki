# &#8216;What a joke&#8217;: Github Copilot&#8217;s new token-based billing spurs consternation among devs

## 中文摘要
GitHub Copilot 将计费模式从固定订阅改为基于 token 的使用量付费，引发开发者强烈不满，认为成本激增且不透明。此举旨在提升微软盈利能力，但可能损害用户忠诚度与产品口碑。对AI产品经理而言，需警惕定价变更对用户留存和市场竞争力的冲击，同时反思按量计费在AI助手类产品中的适用性与透明度设计。
