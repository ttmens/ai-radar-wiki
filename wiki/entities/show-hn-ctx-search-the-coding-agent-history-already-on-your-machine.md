# Show HN: ctx – Search the coding agent history already on your machine

## 中文摘要
 ctx 是一款本地工具，允许开发者搜索已存在于本机的编码代理（如 AI 编程助手）历史记录。通过索引和检索过去的交互日志，帮助用户快速定位之前生成的代码片段、对话或错误信息，减少重复工作，提升开发效率。该产品体现了本地优先的 AI 模式，强调数据隐私和离线可用性，同时利用已有的本地数据创造新的搜索价值，适合集成到开发工作流中。
