# Ultrafast machine learning on FPGAs via Kolmogorov-Arnold Networks

## 中文摘要
本文介绍了一种基于Kolmogorov-Arnold Networks（KAN）在FPGA上实现超快机器学习的方法。KAN通过可学习的激活函数替代传统固定激活函数，显著提升模型表达效率；结合FPGA的并行计算能力，可在低功耗下实现毫秒级推理。该技术为边缘设备、实时AI应用提供了高效硬件加速方案，有望降低对云端算力的依赖，推动AI产品的本地化部署和成本优化。
