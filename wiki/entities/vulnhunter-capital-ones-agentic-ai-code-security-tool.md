# VulnHunter: Capital One's agentic AI code security tool

## 中文摘要
VulnHunter 是 Capital One 推出的基于代理（Agentic）的 AI 代码安全工具，旨在自动化漏洞检测与修复。它利用大模型驱动的智能体自主扫描代码库、识别安全缺陷并生成修复建议，从而减少人工审计成本、加速开发安全流程。该工具体现了 AI 在 DevSecOps 中的深度集成，为产品团队提供了更高效、可扩展的安全保障方案。
