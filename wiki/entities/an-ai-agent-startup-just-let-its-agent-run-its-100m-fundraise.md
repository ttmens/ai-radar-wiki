# An AI agent startup just let its agent run its $100M fundraise

## 中文摘要
专注于企业级AI代理的初创公司Lyzr，使用自家AI代理成功完成1亿美元融资。该代理自主处理了融资过程中的关键环节，包括投资者沟通、文件准备和谈判支持，验证了AI代理在复杂商务流程中的实际能力。这一案例展示了AI代理从辅助工具向核心业务流程执行者的演进，为产品经理提供了AI代理落地企业场景的可行范本，同时暗示了AI代理在资本密集型业务中的潜在价值，以及“自我食用”（dogfooding）作为产品验证策略的有效性。
