# Microsoft turns to AWS as GitHub faces AI capacity crunch

## 中文摘要
微软因GitHub平台AI服务需求激增导致计算容量不足，被迫转向竞争对手AWS获取云资源。这体现了AI能力扩张对基础设施的巨大压力，以及云供应商锁定风险的现实挑战。对AI产品经理而言，需提前规划弹性架构和多云策略，避免单一依赖。
