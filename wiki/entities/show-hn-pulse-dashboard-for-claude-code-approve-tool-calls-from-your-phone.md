# Show HN: Pulse – Dashboard for Claude Code, approve tool calls from your phone

## 中文摘要
Pulse 是一个为 Claude Code 打造的移动端仪表盘，允许用户通过手机远程批准 AI 编程助手的工具调用请求。这一设计解决了 AI 编程场景下工具调用的安全与可控性问题——当 Claude Code 需要执行文件操作、运行命令等敏感动作时，开发者无需守在电脑前即可实时审批。产品创新在于将 AI 交互从桌面延伸至移动端，提升了工作流灵活性与安全性，尤其适合远程协作或需要快速响应的开发环境。对产品经理而言，这展示了如何通过轻量级控制面板降低 AI 工具的使用门槛，同时为未来更多 AI 代理的监督机制提供了参考模式。
