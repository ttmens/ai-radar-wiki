# Agent-Manager: A Tmux TUI for Running Claude Code, Codex and OpenCode

## 中文摘要
Agent-Manager 是一个基于 Tmux 的终端 UI 工具，允许用户同时运行 Claude Code、OpenAI Codex 和 OpenCode 等多个 AI 编码代理。它通过 Tmux 的窗格管理实现多代理并行会话，便于开发者监控和切换不同 AI 助手，提升编程效率。产品创新点在于将多个独立 AI 编码工具整合到统一终端界面，降低工具切换成本，属于“AI 开发工具集成”方向。商业价值体现为减少开发者认知负荷，加速代码生成与调试流程，适合 DevOps 和 AI 辅助编程场景。该模式可启发 PM 设计多代理协作型开发者工具。
