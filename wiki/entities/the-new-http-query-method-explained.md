# The new HTTP QUERY method explained

## 中文摘要
HTTP QUERY 方法是一种新的 HTTP 请求方法，旨在提供安全、幂等的查询操作，避免 GET 请求因 URL 长度限制和日志泄露等问题带来的风险。该方法允许在请求体中传递查询参数，适用于复杂查询、图查询或 AI 服务的 API 设计，提升接口的灵活性和安全性。对于 AI 产品经理，这意味着可以更优雅地设计搜索、检索或知识库查询接口，同时兼容现有 REST 架构。其标准化进程（由 IETF 推动）将影响未来 API 规范，值得关注。
