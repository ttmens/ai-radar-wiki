# Alibaba reportedly bans employees from using Claude Code

## 中文摘要
阿里巴巴据内部公告将Claude Code列为高风险软件并禁止员工使用，此举可能出于数据安全或竞争考量。Claude Code是Anthropic推出的代码生成AI工具，具备强大的编程辅助能力。阿里巴巴的禁令反映了大型科技企业在引入外部AI工具时的合规与数据保护策略，这对AI产品经理意味着需要关注企业级AI工具的准入风险评估、数据主权及供应链安全。该事件也凸显了AI工具在商业环境中的应用边界，可能影响未来产品设计中对第三方AI能力集成的风险控制思路。
