# Ornith-1.0: self-improving open-source models for agentic coding

## 中文摘要
Ornith-1.0 是一款面向智能编码代理的开源自我改进模型。该模型通过自我迭代学习优化编码能力，降低了对人工标注数据的依赖，提升了代码生成与调试的自动化水平。其开源特性有助于社区协作和快速迭代，为产品经理提供低成本、高性能的编码代理基础，有望加速开发者工具和自动化工作流的落地。
