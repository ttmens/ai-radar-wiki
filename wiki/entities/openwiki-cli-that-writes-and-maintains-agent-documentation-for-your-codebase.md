# OpenWiki: CLI that writes and maintains agent documentation for your codebase

## 中文摘要
OpenWiki 是一个命令行工具，专为代码库自动生成并维护面向 AI agent 的文档。它通过解析代码结构，利用大语言模型理解业务逻辑，持续同步更新文档内容，减少人工编写与维护成本。该工具可嵌入开发工作流，提升 agent 对代码的理解准确性和开发效率。其商业价值在于降低团队文档负担、加速 agent 集成，适用于 AI 驱动的开发协作场景。产品创新在于将文档生成与 agent 上下文管理结合，实现文档即代码的自动化闭环。
