# Show HN: SubjectiveZero, an open-source agentic node editor for creative coding

## 中文摘要
SubjectiveZero 是一个开源的代理节点编辑器，专为创意编程设计。它允许用户通过图形化节点连接，构建具有 AI 代理能力的工作流，实现代码生成、数据处理等任务。其核心创新在于将代理机制与节点编辑范式结合，降低了创意编程的复杂度，同时保持高度可扩展性。该项目面向开发者与 AI 产品经理，提供灵活的自定义工作流模板，支持本地部署，适用于快速原型设计和教学场景。技术要点包括基于图的计算模型、代理节点可独立配置 LLM 或工具调用，以及开源社区驱动的生态建设。商业价值在于推动 AI 工具民主化，减少重复编码工作。
