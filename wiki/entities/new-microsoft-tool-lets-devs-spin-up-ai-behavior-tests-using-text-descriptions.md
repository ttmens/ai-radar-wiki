# New Microsoft tool lets devs spin up AI behavior tests using text descriptions

## 中文摘要
微软发布开源框架Adaptive Spec-driven Scoring for Evaluation and Regression Testing，旨在让开发者通过文本描述快速生成AI行为测试。该工具利用规格驱动的自适应评分，简化AI评估与回归测试流程，降低测试门槛。商业价值在于加速AI产品迭代，减少手动测试成本，提升模型可靠性。产品创新点在于将自然语言描述直接转化为可执行的测试逻辑，使非技术专家也能参与质量保障，同时支持持续集成。
