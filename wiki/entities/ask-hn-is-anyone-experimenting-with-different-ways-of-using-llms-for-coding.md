# Ask HN: Is anyone experimenting with different ways of using LLMs for coding?

## 中文摘要
HN社区正在探讨使用LLM进行编码的创新方式，超越传统的代码补全和生成。产品经理应关注如何通过非传统交互（如对话式调试、多步骤重构）将LLM融入开发工作流，以提升开发者效率。实验方向包括上下文感知的代码修改、基于自然语言的工作流编排等，核心价值在于降低认知负荷和加速原型迭代。潜在的商业机会在于打造更智能的IDE插件或自动化编码工具，但需平衡控制性与灵活性。
