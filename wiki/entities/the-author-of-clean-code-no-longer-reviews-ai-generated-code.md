# The Author of Clean Code No Longer Reviews AI-Generated Code

## 中文摘要
《Clean Code》作者Robert C. Martin（Bob大叔）公开表示不再审查AI生成的代码，认为当前AI代码质量不可靠，存在逻辑错误和安全隐患。这一态度反映了开发者社区对AI编程助手能力边界的质疑，对依赖AI生成代码的产品团队构成信任挑战。产品经理需关注AI代码的可审性、质量评估标准以及如何建立人机协作的代码审查机制。事件提示AI编程工具应增强可解释性和可控性，减少黑箱输出，同时推动社区建立AI代码质量基准。
