# Infomaniak transitions to a foundation model to protect user data privacy

## 中文摘要
瑞士云服务商Infomaniak宣布将其AI服务转向自主基础模型，以强化用户数据隐私保护。此举旨在减少对第三方模型依赖，通过本地化部署和联邦学习技术，确保用户数据不离开欧洲境内，满足GDPR合规要求。商业价值在于差异化竞争，吸引注重隐私的企业客户；产品创新体现在将隐私保护作为核心设计原则，而非事后添加。该方案可能降低模型性能，但换取了更高安全性和用户信任。
