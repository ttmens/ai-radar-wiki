# OpenAI reduces Codex Model Context Size from 372k to 272k

## 中文摘要
OpenAI 将 Codex 模型的上下文长度从 372k tokens 缩减至 272k，降幅约 27%。这一优化可能通过模型架构改进或训练策略调整实现，旨在降低推理成本和延迟，同时保持代码生成质量。对于 AI 产品经理，这意味着 Codex 在实际应用中（如代码补全、智能编程助手）的响应速度更快、部署成本更低，但需要评估长上下文场景（如跨文件代码理解）是否受到影响。该变化可能推动 Codex 在资源受限环境下的产品落地，提升商业化竞争力。
