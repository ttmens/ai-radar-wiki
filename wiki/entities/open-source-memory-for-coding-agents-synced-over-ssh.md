# Open-source memory for coding agents, synced over SSH

## 中文摘要
本新闻介绍了一个开源项目，旨在为编码代理（如AI编程助手）提供持久化记忆功能，并通过SSH进行跨设备同步。这对于产品经理而言，意味着可以构建更智能、更具上下文感知能力的编程辅助工具，无需依赖第三方云服务。技术要点：采用本地优先架构，利用SSH实现安全同步，支持用户自托管。商业价值：降低企业数据外泄风险，增强用户信任，同时开源特性促进社区定制。产品创新：将短期对话记忆升级为长期工作记忆，提升连续编程任务的效率。
