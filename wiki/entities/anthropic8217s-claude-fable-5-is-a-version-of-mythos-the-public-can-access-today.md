# Anthropic&#8217;s Claude Fable 5 is a version of Mythos the public can access today

## 中文摘要
Anthropic 发布 Claude Fable 5，这是其首个面向公众开放的 Mythos 类模型。该模型通过内置安全护栏，严格限制在网络安全、生物学等高危领域的响应，平衡了能力与风险控制。对AI产品经理而言，此举标志着前沿模型在开放性与安全性之间找到新平衡点，可能推动企业级应用采纳，但需评估其对于垂直场景的实用性。
