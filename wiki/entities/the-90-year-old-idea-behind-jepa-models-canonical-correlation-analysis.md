# The 90-year-old idea behind JEPA models: Canonical Correlation Analysis

## 中文摘要
JEPA（联合嵌入预测架构）基于90年前的典型相关分析（CCA）思想，通过预测表征空间中的嵌入来学习，避免了对像素级重建的依赖，显著降低计算成本。这种自监督学习方法提升了模型的数据效率与泛化能力，尤其适合大规模预训练场景。对AI产品经理而言，JEPA有望降低基础模型的训练成本，加速产品迭代，并为多模态理解、视频预测等任务提供更高效的解决方案。其技术本质是优化表征学习，与LLM的next token prediction路径不同，开辟了新的能力演进方向。
