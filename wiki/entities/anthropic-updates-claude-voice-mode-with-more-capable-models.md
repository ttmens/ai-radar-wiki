# Anthropic updates Claude voice mode with more capable models

## 中文摘要
Anthropic 为 Claude 推出升级版语音模式，搭载更强大模型，支持用户通过语音指令完成会议重新安排、邮件起草等具体任务。该更新显著提升了语音交互的实用性和任务完成能力，将 AI 从对话工具拓展为生产力助手。技术要点在于模型在多轮对话与意图理解上的增强，商业价值体现在企业办公场景中提升效率，产品创新则是将语音交互与具体任务执行深度融合，降低用户操作门槛。
