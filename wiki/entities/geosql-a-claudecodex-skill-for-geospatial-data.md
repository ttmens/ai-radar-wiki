# Geosql: A Claude/Codex skill for geospatial data

## 中文摘要
Geosql 是一个针对 Claude 和 Codex 开发的技能，旨在让大语言模型能够理解和执行地理空间数据查询。通过自然语言接口，用户无需掌握复杂 SQL 或 GIS 工具即可获取空间分析结果。该技能降低了地理空间数据的使用门槛，赋能城市规划、物流优化、环境监测等领域的决策效率。产品创新在于将 AI 的对话能力与地理空间数据库深度结合，形成“提问即分析”的交互模式，有望推动地理智能应用的普及。
