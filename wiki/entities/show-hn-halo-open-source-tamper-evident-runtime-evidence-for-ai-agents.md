# Show HN: Halo – open-source, tamper-evident runtime evidence for AI agents

## 中文摘要
Halo是一个开源工具，为AI代理提供防篡改的运行时证据。它通过记录代理执行过程中的关键操作并生成加密可验证的日志，确保行为不可否认和可审计。该工具解决了企业级AI应用中代理行为的可信任与合规性问题，尤其适用于金融、医疗等强监管领域。产品创新点在于将区块链的防篡改概念引入AI代理监控，无需依赖第三方断言即可独立验证代理行为。商业价值在于提升AI代理的透明度，降低部署风险，加速企业采用自主代理。
