# Decart&#8217;s new world model can simulate hours of photorealistic driving — with some caveats

## 中文摘要
Decart 推出 Oasis 3，这是一个实时世界模型，能够生成照片级逼真的驾驶环境，用于自动驾驶汽车的测试。该模型通过 API 提供给开发者，无需专用硬件即可快速构建和迭代仿真场景。技术核心在于实时生成高保真道路、交通与光照变化，大幅降低物理测试成本并提升训练数据多样性。产品创新体现在将世界模型作为云服务开放，使中小团队也能获取高质量自动驾驶仿真能力。商业价值显著，可加速自动驾驶技术的落地与安全验证。
