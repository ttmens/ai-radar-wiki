# OpenAI unveils Lockdown Mode to protect sensitive data from prompt injection attacks

## 中文摘要
OpenAI 推出 Lockdown Mode 以防范提示注入攻击，该模式旨在减少敏感数据在对话中被泄露的风险。尽管无法完全免疫，但通过限制模型对特定指令的响应，提升了安全性。对产品经理而言，这一功能有助于构建更可信的 AI 应用，尤其适合金融、医疗等数据敏感场景，降低合规风险。它体现了从功能驱动向安全优先的设计转变，是 AI 产品中数据保护能力的重要创新。
