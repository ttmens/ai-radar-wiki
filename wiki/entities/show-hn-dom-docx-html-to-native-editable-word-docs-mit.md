# Show HN: DOM-docx – HTML to native, editable Word docs (MIT)

## 中文摘要
DOM-docx 是一个开源工具（MIT 许可证），能够将 HTML 内容转换为原生、可编辑的 Word 文档（.docx 格式）。不同于常见 HTML 转 PDF 方案，它保留了文档的编辑性和格式灵活性，非常适合集成到 AI 写作助手、内容生成产品中，使 AI 输出可直接用于 Word 编辑与协作。该工具基于 DOM 解析实现，轻量且易扩展，对于需要将 AI 生成报告、文案、表格等输出为专业文档的产品团队具有实用价值，可降低人工调整格式的成本，加速内容生产到交付的流程。
