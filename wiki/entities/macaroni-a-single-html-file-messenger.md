# Macaroni – a single HTML file messenger

## 中文摘要
Macaroni 是一个仅用单个 HTML 文件实现的轻量级即时通讯工具，无需后端服务器或复杂依赖，可自托管使用。技术核心在于将完整的前端交互、数据存储和通信逻辑封装在单一文件中，实现极简部署与高可移植性。商业价值体现在降低隐私通讯门槛，适合对数据安全敏感的小团队或个人；产品创新在于通过极简架构颠覆传统消息应用的臃肿体验，可快速分享给任意用户。对 AI 产品经理而言，该案例展示了极端封装与去中心化设计的可行性，但缺乏 AI 原生特性，相关性中等。
