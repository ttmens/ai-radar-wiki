# headroomlabs-ai/headroom

## 概览
Compress tool outputs, logs, files, and RAG chunks before they reach the LLM. 60-95% fewer tokens, same answers. Library, proxy, MCP server.

## 中文摘要
Headroom 是一个开源工具库，可在数据到达大语言模型前对工具输出、日志、文件和 RAG 分块进行压缩，减少 60%-95% 的 token 消耗，同时保持回答质量。它支持作为库、代理或 MCP 服务器集成，能显著降低 LLM 调用成本，提升推理效率和系统吞吐量。对 AI 产品经理而言，该方案直接降低了运营成本，并让现有 RAG 或工具调用流程更经济、可扩展，适合高并发或耗 token 敏感的场景。
