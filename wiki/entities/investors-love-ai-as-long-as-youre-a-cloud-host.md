# Investors love AI, as long as you’re a cloud host

## 中文摘要
文章指出，投资者对AI的热情呈现明显分化，真正受到青睐的是像亚马逊这样的大型云服务提供商。尽管亚马逊在数据中心上的资本支出持续加码，投资者却并未表示反对，反而给予认可。这反映出市场对AI基础设施投入的理性支持，云厂商凭借算力资源和规模效应，成为AI浪潮中的核心受益者。对AI产品经理而言，这一趋势意味着底层算力供给将长期向头部云厂商集中，产品设计需考虑对云生态的依赖，同时关注资本开支带来的服务成本与定价变化。云基础设施建设仍是AI商业化落地的重要支撑。
