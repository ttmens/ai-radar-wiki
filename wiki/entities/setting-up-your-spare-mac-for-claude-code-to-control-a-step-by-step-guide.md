# Setting up your spare Mac for Claude Code to control, a step-by-step guide

## 中文摘要
本文介绍如何将备用Mac配置为Claude Code（Anthropic的AI编码助手）的控制节点，实现AI直接操作本地开发环境。作为面向开发者的实操指南，它降低了AI代理本地部署的门槛，让开发者通过CLI指令让Claude执行代码测试、文件管理等任务。技术要点包括SSH远程控制、环境变量配置与权限管理；商业价值体现在提升开发效率、减少手动操作；产品创新在于将大模型从“建议者”变为“执行者”，推动AI代理在终端场景的落地。
