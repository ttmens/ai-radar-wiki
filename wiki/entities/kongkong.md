## 中文摘要
Kong 是一款开源 API 和 AI 网关，支持传统 API 管理与 AI 模型路由、安全、可观测性等能力，帮助产品经理统一管理传统服务与 AI 推理端点，降低集成成本并提升系统灵活性。其商业价值在于为企业提供标准化、可扩展的网关层，加速 AI 能力的落地。产品创新体现在将 AI 网关功能（如模型路由、速率限制、多模型切换）无缝嵌入现有 API 基础设施中。
