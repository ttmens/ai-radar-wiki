# RasaHQ/rasa

## 概览
💬   Open source machine learning framework to automate text- and voice-based conversations: NLU, dialogue management, connect to Slack, Facebook, and more - Create chatbots and voice assistants

## 中文摘要
Rasa是一个开源机器学习框架，专注于构建文本和语音对话系统，提供自然语言理解（NLU）与对话管理两大核心模块，支持Slack、Facebook等多平台集成。其技术要点在于采用端到端的数据驱动方法，使开发者能够自定义意图识别、实体提取和对话流程，并支持在线学习和持续改进。商业价值体现在降低企业构建智能客服和语音助手的成本，避免依赖单一云服务商，实现本地化部署和数据隐私控制。产品创新在于将NLU和对话管理解耦又协同，提供灵活的中间件和策略训练，适合需要高度定制化对话体验的场景。
