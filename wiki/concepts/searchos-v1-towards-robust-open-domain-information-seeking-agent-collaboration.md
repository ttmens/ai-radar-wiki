# SearchOS-V1: Towards Robust Open-Domain Information-Seeking Agent Collaboration

## 中文摘要
SearchOS-V1 提出了一种面向开放域信息搜索的鲁棒代理协作框架。针对工具集成大语言模型在长交互历史中任务跟踪困难、搜索失败时缺乏有效证据的问题，该工作设计了多代理协作机制，能够动态调整搜索策略并整合多方信息。其核心创新在于通过结构化内存和协作协议提升搜索鲁棒性，降低错误累积，为构建更可靠的AI信息助手提供了新范式。对产品经理而言，该技术可应用于智能客服、知识检索、研究辅助等场景，提升复杂信息查询的准确性和用户体验。
