# AIR: Adaptive Interleaved Reasoning with Code in MLLMs

## 中文摘要
本文提出自适应交错推理（AIR）方法，旨在提升多模态大语言模型（MLLM）的推理能力。受OpenAI o3范式启发，AIR在视觉感知任务中动态结合代码执行与语言推理，通过自适应策略决定何时调用代码模块，以处理需要精确计算或逻辑推导的场景。该方法增强了MLLM在数学、图表和复杂视觉问答等任务中的准确性与可解释性，同时降低了纯视觉推理的误差。商业价值上，AIR可赋能自动化文档分析、科学图像理解等产品，提升多模态AI在行业应用中的可信度；产品创新在于将代码推理无缝嵌入多模态流程，支持更灵活的人机协作。
