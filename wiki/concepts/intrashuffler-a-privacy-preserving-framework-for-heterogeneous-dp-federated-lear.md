# IntraShuffler: A Privacy Preserving Framework for Heterogeneous DP Federated Learning

## 中文摘要
IntraShuffler 是一种针对异构差分隐私联邦学习的新型隐私保护框架。它允许客户端根据自身策略和数据敏感性选择不同的隐私预算（ε_i），并通过 ε-aware 服务器聚合机制提升模型效用。该框架在保护用户隐私的同时，有效缓解了异质性隐私预算带来的模型性能下降问题，为医疗、金融等强隐私场景下的联邦学习落地提供了实用方案。产品经理可关注其平衡隐私与效用的能力，降低企业合规风险，加速数据协作。
