# A Methodology for Selecting and Composing Runtime Architecture Patterns for Production LLM Agents

## 中文摘要
本文提出将生产级LLM代理中的随机模型输出与确定性软件系统之间的边界作为一等架构对象——随机-确定性边界（SDB），并定义了包含提议者、验证者等四部分合约。该方法论为选择和组合运行时架构模式提供了系统框架，帮助产品经理设计更可靠、可组合的LLM应用，降低不确定性风险，提升系统稳定性和商业价值。
