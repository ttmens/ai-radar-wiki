# Provable diffusion-based posterior sampling for linear inverse problems via DDIM

## 中文摘要
该论文提出一种基于DDIM的可证明扩散后验采样算法（PDDIM），用于解决线性逆问题。现有扩散后验采样方法要么缺乏严格理论保证，要么计算成本高。PDDIM在保持高效的同时提供了理论收敛保证，可应用于图像修复、超分辨率、去噪等任务，提升产品可靠性与效率，降低计算资源需求。
