# Early Adoption of Agentic Coding Tools by GitHub Projects

## 中文摘要
该论文研究GitHub项目对代理式编码工具的早期采用情况。这类工具能自动生成并提交拉取请求（PR），标志着软件开发中新型人机协作模式的兴起。尽管已有研究关注AI生成PR的结果，但对工具本身采用模式和协作效果的分析仍不充分。产品经理可关注其提升开发效率、降低人工审查成本的潜力，以及未来集成到CI/CD流程的可行性。
