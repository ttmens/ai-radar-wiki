# A welding penetration prediction model for laser welding process based on self-supervised learning using physics-informed neural networks

## 中文摘要
本文提出SimPhysNet，一种基于自监督学习和物理信息神经网络（PINNs）的激光焊接穿透预测模型。该模型结合物理约束与自监督学习范式，无需大量标注数据即可精确预测焊接全穿透状态，对实现无缺陷焊接接头、提升产品质量至关重要。技术核心在于将焊接物理过程编码为网络损失函数，增强模型可解释性与泛化能力。商业价值体现在可集成至智能焊接系统，降低废品率与人工检测成本，推动制造业AI落地。产品创新在于将领域物理知识与自监督表征学习相融合，为工业缺陷预测提供新范式。
