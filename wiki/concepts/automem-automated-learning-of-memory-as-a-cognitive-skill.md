# AutoMem: Automated Learning of Memory as a Cognitive Skill

## 中文摘要
AutoMem 将记忆管理视为一种可训练的认知技能（元记忆），旨在让 LLM 自主学会编码、检索和组织知识。通过把文件系统操作提升为第一类操作，AutoMem 使模型能够动态管理长期上下文，提升记忆的自主性与适应性。这项技术为 AI 产品提供了更智能的长期记忆解决方案，有望减少人工干预，推动基于记忆的个性化交互与知识管理创新。
