# Network Recovery from Cascade Data: A Debiased Jacobian-Based Machine Learning Approach

## 中文摘要
本文提出一种基于去偏雅可比的机器学习方法，用于从级联数据中恢复隐藏的因果影响网络。传统方法通常依赖特定的扩散模型假设（如独立级联、线性阈值模型），导致泛化能力受限。该方法通过雅可比矩阵去偏估计，无需假设具体的扩散机制，即可从观察到的级联时序数据重建网络拓扑。该技术对产品经理的价值在于：可应用于社交网络传播路径挖掘、疫情传播链溯源、金融风险传导分析、信息扩散效率优化等场景。例如，识别关键影响者、预测病毒式传播、或优化推荐系统的用户影响力建模。该方法降低了模型假设偏见，提升了网络推断的鲁棒性和准确性，为基于级联数据的产品功能（如社交传播分析、用户行为归因）提供更可靠的技术底座。
