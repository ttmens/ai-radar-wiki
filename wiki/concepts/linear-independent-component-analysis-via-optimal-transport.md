# Linear Independent Component Analysis via Optimal Transport

## 中文摘要
该论文研究线性独立成分分析（ICA），旨在从线性混合信号中恢复相互独立的源信号。经典ICA算法通过最大化非高斯性（以负熵度量）来实现，负熵与信息论中的独立性概念紧密相关。本文提出利用最优传输理论来改进ICA方法，可能提升分离精度和鲁棒性。对于AI产品经理，该技术可应用于语音分离、脑电信号处理、金融数据去噪等场景，作为数据预处理或特征提取的底层能力。但当前仍偏理论探索，离商业化落地较远，需关注后续验证。
