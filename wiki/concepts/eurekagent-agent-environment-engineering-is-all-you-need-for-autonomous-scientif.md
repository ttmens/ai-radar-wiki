# EurekAgent: Agent Environment Engineering is All You Need For Autonomous Scientific Discovery

## 中文摘要
EurekAgent 提出了一种基于 LLM 的智能体环境工程方法，用于自主科学发现。核心思路是：给定一个可优化的度量和执行环境，智能体能够自主提出假设、设计实验、执行验证并迭代改进，最终产生超越人类设计的科学解决方案。该技术将科研流程自动化，显著降低人力成本并加速发现周期，尤其在药物研发、材料科学等需要大规模试错的领域具有商业价值。产品创新点在于将环境工程作为核心抽象，使智能体无需人类干预即可进行闭环科学探索，拓展了 AI 在科研领域的应用边界。
