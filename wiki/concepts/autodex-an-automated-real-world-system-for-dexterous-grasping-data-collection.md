# AutoDex: An Automated Real-World System for Dexterous Grasping Data Collection

## 中文摘要
AutoDex 提出了一种自动化真实世界系统，用于灵巧抓取数据的收集。当前灵巧抓取学习面临真实世界数据稀缺的瓶颈：遥操作收集数据准确但效率低且存在操作者偏差，仿真数据易扩展但物理真实性不足。该系统通过自动化物理尝试记录抓取结果，实现了大规模高质量真实数据采集，为训练鲁棒的灵巧抓取策略提供了关键数据基础，有望加速机器人灵巧操作能力的商业化落地。
