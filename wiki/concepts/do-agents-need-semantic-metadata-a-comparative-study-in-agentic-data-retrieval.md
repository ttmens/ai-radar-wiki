# Do Agents Need Semantic Metadata? A Comparative Study in Agentic Data Retrieval

## 中文摘要
该论文研究了自主智能体在数据检索过程中是否需要语义元数据（如 schema.org）。通过对比分析，探讨了语义元数据如何支撑 FAIR 原则，提升数据的可发现性、可访问性、互操作性和可重用性。对于 AI 产品经理而言，核心价值在于：语义元数据可帮助智能体更高效地理解和使用异构数据源，减少信息孤岛，推动数据驱动工作流的自动化。产品创新方向包括构建元数据增强的智能体检索框架，以及将语义标准嵌入到 Agent 的数据交互流程中，从而提升 Agent 的决策质量和跨系统协作能力。
