# Stateful Online Monitoring Catches Distributed Agent Attacks

## 中文摘要
本文提出一种状态在线监控方法，用于检测分布式Agent攻击。大语言模型可发现数千个严重软件漏洞，而Agent正被滥用于网络攻击。攻击者常将有害任务分散到多个用户账户，使单个对话看似无害，从而规避检测。该监控系统通过持续跟踪对话状态和跨会话行为，识别分布式恶意模式。对产品经理而言，这为AI Agent的安全部署提供了关键防护机制，确保企业级应用免受隐蔽攻击，同时维护用户体验。技术亮点在于能够在不降低响应速度的前提下实现实时状态聚合与分析。
