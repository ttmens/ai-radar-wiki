# MUSE-Autoskill: Self-Evolving Agents via Skill Creation, Memory, Management, and Evaluation

## 中文摘要
MUSE-Autoskill提出一种自进化AI代理框架，通过动态技能创建、记忆管理、评估与存储，解决现有技能孤立静态的问题。核心创新在于代理能基于经验持续改进技能库，提升复用性和可靠性，实现长期自我进化。对产品经理而言，该技术可构建更智能、自适应能力更强的AI助手，降低人工干预成本，适用于复杂任务自动化、个人助理等领域，具有显著商业价值。
