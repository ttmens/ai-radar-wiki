# PalmClaw: A Native On-Device Agent Framework for Mobile Phones

## 中文摘要
PalmClaw 提出了一个原生运行在移动设备上的智能体框架，使大语言模型代理能在手机端直接执行多步骤任务（如调用 API、观察结果并迭代决策），而无需依赖云端推理。该框架针对移动硬件的限制进行优化，支持本地工具调用和自动化，在保护用户隐私、降低延迟和离线场景下具有显著优势。对于产品经理而言，这一框架可推动移动端原生 AI 助手（如语音助理、自动化工作流）的实现，开启手机端低延迟、高隐私的智能体应用新范式。
