# CottonLeafVision: An Explainable and Robust Deep Learning Framework for Cotton Leaf Disease Classification

## 中文摘要
CottonLeafVision 是一个针对棉花叶病分类的可解释且鲁棒的深度学习框架。该框架旨在通过精确识别与检测棉花叶部病害，保障纺织业原料供应的经济稳定性。技术要点包括利用可解释性机制提升模型透明度，增强对复杂田间环境的鲁棒性，从而降低误诊率。商业价值体现在提高棉花产量与质量，减少农药浪费，为农业AI产品提供可落地的垂直场景解决方案。产品创新在于将可解释性融入分类模型，使得农业从业者能够信任并理解AI决策，推动AI在精准农业中的实际部署。
