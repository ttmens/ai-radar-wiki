# AgentHPOBench: A Benchmark For Evaluating LLM Agents as Sequential Hyperparameter Optimizers

## 中文摘要
AgentHPOBench是一个用于评估LLM智能体作为顺序超参数优化器能力的基准。现有基准多聚焦于静态代码生成、论文复现或最终答案正确性，无法直接评估智能体自主设计实验和迭代优化的能力。该基准通过模拟超参数调优任务，检验LLM智能体在多轮决策中的表现，涵盖观察历史、调整策略、利用反馈等关键环节。对AI产品经理而言，它填补了科学发现智能体能力评估的空白，为构建自主实验型AI产品提供了标准化测试方法，并有助于推动AI从代码生成向科学助理演进。
