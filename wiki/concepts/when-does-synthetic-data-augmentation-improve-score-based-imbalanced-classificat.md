# When Does Synthetic Data Augmentation Improve Score-Based Imbalanced Classification?

## 中文摘要
该论文研究了合成数据增强在基于分数的分类任务中缓解类别不平衡问题的理论效果。作者提出一个框架，用于刻画合成少数类数据增强何时能改善阈值集成与阈值优化分类性能。研究发现，合成增强并非总是有效，其效果取决于数据分布和分类器特性。对于产品经理而言，该研究可指导在不平衡数据场景（如欺诈检测、罕见事件预测）中合理使用合成数据，避免盲目增强带来的负面效果，从而提升模型在实际应用中的鲁棒性与商业价值。
