# MM-ToolSandBox: A Unified Framework for Evaluating Visual Tool-Calling Agents

## 中文摘要
MM-ToolSandBox 是一个面向视觉工具调用代理的统一评估框架，提供了包含500多个工具、覆盖16个应用领域的状态化执行环境。该框架支持多图像、多轮交互任务，要求代理在逐步获取信息的基础上进行工具调用。对于AI产品经理而言，该框架能够标准化评估视觉AI代理的工具使用能力和任务完成效果，有助于加速相关产品的研发迭代和质量控制，同时为构建更可靠的自动化视觉工作流程奠定基础。
