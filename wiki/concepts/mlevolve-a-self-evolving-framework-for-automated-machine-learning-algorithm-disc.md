# MLEvolve: A Self-Evolving Framework for Automated Machine Learning Algorithm Discovery

## 中文摘要
MLEvolve提出一种自进化框架，用于自动机器学习算法发现。针对现有LLM代理在长期任务中存在的分支间信息隔离和无记忆搜索问题，该框架通过自我进化机制持续优化算法选择与组合，提升自动化机器学习效率。技术要点包括自监督学习、记忆模块与迭代探索策略。商业价值在于降低机器学习模型开发的人工成本，加速算法迭代。产品创新在于将LLM代理的自我进化能力应用于算法发现，实现自动化与持续优化。
