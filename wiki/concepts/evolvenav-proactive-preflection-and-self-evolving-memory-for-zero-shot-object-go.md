# EvolveNav: Proactive Preflection and Self-Evolving Memory for Zero-Shot Object Goal Navigation

## 中文摘要
EvolveNav 提出了一种面向零样本目标导航的自适应框架，通过主动预反射和自进化记忆机制，解决现有基础模型因静态先验导致的重复错误问题。其核心创新在于：模型在探索过程中动态修正记忆，避免陷于局部最优，从而提升目标定位效率。商业价值上，该技术可降低机器人或自动驾驶系统对新环境的预训练依赖，加速部署并节约算力成本。产品创新方面，将记忆模块与动态推理结合，为无预设场景的自主导航提供了更鲁棒的解决方案。
