# Semantic Browsing: Controllable Diversity for Image Generation

## 中文摘要
该论文提出了迭代推理方法，在不增加计算预算的情况下提升长上下文推理效率。通过将长序列拆分为可管理的块并逐步整合推理路径，模型能更精准地引用关键信息，减少注意力分散。对产品经理而言，这意味着能降低长文档问答或代码分析场景的延迟与成本，同时保持输出质量。商业价值在于可部署于需要处理超长输入的聊天机器人、文档摘要工具等，提升用户体验。
