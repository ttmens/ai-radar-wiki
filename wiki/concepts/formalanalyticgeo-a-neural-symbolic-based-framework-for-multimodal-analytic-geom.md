# FormalAnalyticGeo: A Neural-Symbolic Based Framework for Multimodal Analytic Geometry Problem Generation

## 中文摘要
该论文提出FormalAnalyticGeo框架，通过神经符号方法解决多模态大语言模型在解析几何领域的数据稀缺问题，能够自动生成带图表的高质量解析几何题目。技术亮点在于结合符号推理与神经网络，提升生成题目的逻辑一致性和多样性，为教育科技产品提供自动化出题能力，降低人工标注成本，具有显著的商业价值。
