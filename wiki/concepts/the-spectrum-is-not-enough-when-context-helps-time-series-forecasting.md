# The Spectrum Is Not Enough: When Context Helps Time-Series Forecasting

## 中文摘要
该论文指出，当前流行的时间序列可预测性评分（基于频谱分析）常被误读为衡量“加入上下文（如更长历史窗口、检索插件或预训练模型）”是否有效。实际上，频谱可预测性与上下文增益是两个不同问题。面向AI产品经理，该研究提醒在设计预测类功能（如库存、流量预测）时，需区分数据本身的频谱特性与外部上下文带来的增值，避免依赖单一指标评估模型选型。这有助于更精准地评估上下文增强方案的投资回报，优化产品决策。
