# Data Intelligence Agents: Interpreting, Modeling, and Querying Enterprise Data via Autonomous Coding Agents

## 中文摘要
Data Intelligence Agents (DIA) 是一个多代理系统，通过三个自主编码代理（数据解释器、模式创建器、查询引擎）自动化企业数据的解释、建模和查询。它解决了传统数据集成中数据所有者、工程师和分析师之间重复且损失严重的交接问题，显著提升生产效率。该方案将AI作为数据流水线的智能编排层，降低了数据集成的人力成本和错误率，为企业数据治理提供了可扩展的AI驱动模式。对于AI产品经理而言，这是一个典型的多代理协作与代码生成结合的产品创新案例。
