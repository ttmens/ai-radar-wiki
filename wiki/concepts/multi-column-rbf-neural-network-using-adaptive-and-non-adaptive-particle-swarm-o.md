# Multi-Column RBF Neural Network Using Adaptive and Non-Adaptive Particle Swarm Optimization

## 中文摘要
本文提出一种基于自适应与非自适应粒子群优化的多列径向基函数神经网络(RBFN)训练方法。传统梯度下降算法在训练RBFN时容易陷入局部最优，而该研究通过粒子群优化(PSO)自适应选择隐层神经元，结合误差校正机制提升网络收敛速度与泛化能力。其多列结构增强了模型对复杂模式的学习能力，适用于分类与回归任务。商业价值在于能更高效地训练轻量级神经网络，减少对大规模标注数据和算力的依赖，可应用于实时预测、异常检测等场景，为边缘AI产品提供低成本、高精度的解决方案。
