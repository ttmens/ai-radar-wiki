# GPU-Parallel Linearization Error Bounds for Real-Time Robust Optimal Control of Nonlinear and Neural Network Dynamics

## 中文摘要
本文研究不确定非线性系统的实时鲁棒最优控制，采用线性时变近似以提高规划效率，但需精确的线性化误差边界（LEB）保证鲁棒约束满足。作者开发了紧致、可微且支持GPU并行计算的LEB方法，可应用于包含神经网络动力学模型的场景。该方法能在毫秒级完成边界计算，显著提升自动驾驶、机器人等实时控制系统的安全性和鲁棒性。产品创新在于将GPU并行计算与鲁棒控制理论结合，为实时决策系统提供可靠的理论支撑。
