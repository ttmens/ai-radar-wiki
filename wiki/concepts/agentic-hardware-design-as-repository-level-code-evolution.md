# Agentic Hardware Design as Repository-Level Code Evolution

## 中文摘要
HORIZON 提出了一种自进化智能体框架，将硬件设计视为仓库级代码演化过程。通过将 Markdown 说明书编译为包含领域知识、可执行评估器、验收谓词及 git/运行时策略的项目包，智能体无需人工干预即可自动迭代优化硬件设计方案。该技术降低了硬件设计门槛，加速了从需求到实现的闭环，体现了 AI 在产品创新中的自动化与自适应性，适合硬件敏捷开发。
