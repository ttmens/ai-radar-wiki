# Using AI-based Learning Assistants in Higher Education: A Large-Scale Descriptive Analysis

## 中文摘要
本研究基于7.7万余名远程教育学生的客观日志数据，对AI学习助手Syntea的使用模式进行了大规模描述性分析，覆盖性别、年龄、学科集群和学位等维度。研究发现不同人群在使用频率、时长和功能偏好上存在显著差异，为教育产品经理优化AI辅助学习体验、实现个性化干预提供了数据驱动的洞察。该研究展示了AI在教育场景下的落地价值，其方法论可迁移至其他垂直领域的产品分析。
