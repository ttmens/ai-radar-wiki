# Learning Adaptive Safety Margins for Visual Navigation

## 中文摘要
本文提出自适应安全裕度方法，解决机器人在室内环境中因固定安全裕度校准不当导致的导航失败问题。保守裕度造成绕路和超时，宽松裕度在感知偏差下引发近边界捷径风险。该方法利用扩散模型动态调整安全距离，平衡效率与安全性。技术要点：基于学习的安全裕度调节、视觉导航中的碰撞避免。商业价值：提升服务机器人、仓储物流等场景的自主导航可靠性与运行效率。产品创新：从静态参数转向动态自适应，减少人工调参成本。
