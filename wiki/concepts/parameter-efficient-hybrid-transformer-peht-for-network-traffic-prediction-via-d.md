# Parameter Efficient Hybrid Transformer (PEHT) for Network Traffic Prediction via Dynamic Urban Congestion Integration

## 中文摘要
该论文提出了一种参数高效的混合Transformer模型（PEHT），用于动态城市蜂窝网络中的流量预测。传统预测方法难以处理复杂移动模式、拥堵动态和异质用户行为。PEHT通过轻量级架构减少计算成本，并创新性地将实时城市拥堵数据作为外部特征融入Transformer，从而显著提升预测准确性。对AI产品经理而言，该技术可直接应用于电信网络资源动态分配，降低运营成本并改善用户体验。其混合架构和参数高效设计也为其他时序预测场景（如交通、物流）提供了可迁移的范式，具有较高的产品落地潜力。
