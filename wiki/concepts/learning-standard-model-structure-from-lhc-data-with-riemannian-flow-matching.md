# Learning Standard Model structure from LHC data with Riemannian flow matching

## 中文摘要
本文展示了基于Transformer的生成式模型ShellFlow能够从LHC（大型强子对撞机）数据中学习标准模型结构，覆盖从亚GeV到TeV连续谱五个数量级的不变质量范围，远超单一蒙特卡罗样本的覆盖能力。该模型采用黎曼流匹配技术，实现了高质量、跨能区的物理事件生成。其商业价值在于替代传统耗时且昂贵的蒙特卡罗模拟，显著降低高能物理数据分析的计算成本与时间。产品创新体现在将生成式AI应用于科学模拟领域，为复杂物理过程的快速建模提供新范式。
