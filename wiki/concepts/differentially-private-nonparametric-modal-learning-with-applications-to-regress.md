# Differentially Private Nonparametric Modal Learning with Applications to Regression and Clustering

## 中文摘要
本文研究在严格差分隐私约束下，如何从多变量分布中恢复密度模态（即局部峰值），用于回归和聚类任务。该方法基于局部光滑性假设，提出非参数模态学习的隐私保护算法，兼顾统计效用与隐私保证。对AI产品经理而言，该技术可在用户数据敏感场景（如个性化推荐、健康分析）中实现可解释的分布洞察，同时满足合规要求，推动隐私增强型数据分析产品的落地。
