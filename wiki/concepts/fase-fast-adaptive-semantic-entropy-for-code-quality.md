# FASE: Fast Adaptive Semantic Entropy for Code Quality

## 中文摘要
该论文提出FASE（快速自适应语义熵），用于评估多智能体代码生成系统中的代码质量。针对LLM幻觉和跨智能体错误传播问题，FASE通过自适应语义熵来量化生成代码的不确定性，从而提升系统可靠性。技术要点包括快速自适应计算熵值、结合代码语义特征。商业价值在于提高自动代码生成的质量和稳定性，降低人工审查成本，适用于AI辅助软件工程。产品创新体现在将熵度量引入多智能体协作场景，实现实时质量监控。
