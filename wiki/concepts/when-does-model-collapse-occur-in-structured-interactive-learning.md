# When Does Model Collapse Occur in Structured Interactive Learning?

## 中文摘要
该论文研究在结构化交互学习环境中模型崩溃发生的条件。随着生成式AI普及，模型参数不断通过自然数据和合成数据更新。研究表明，过度依赖其他模型生成的合成数据进行训练会导致模型性能退化、多样性丧失（模型崩溃）。技术要点：需控制合成数据比例、设计交互学习策略。商业价值：对持续学习的AI产品（如推荐系统、对话助手）至关重要，避免模型退化。产品创新：可启发建立数据溯源和质量监控机制，确保学习稳定。
