# Second-Order Path Kernel Interpolation Formulas in Machine Learning

## 中文摘要
该论文提出了一种基于二阶路径核的插值公式，用于解释确定性梯度下降训练的神经网络如何受训练数据影响。它通过沿优化路径的积分形式表达模型预测，从而提供理论工具来量化每个训练样本对最终预测的贡献。对于AI产品经理，此成果可提升模型可解释性，优化数据选择策略，降低调试成本，并增强用户对AI决策的信任。
