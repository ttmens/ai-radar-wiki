# Bridging Physical Reasoning and Task Generalization via Visual Action Outcome Reasoning Alignment

## 中文摘要
本篇论文探讨了视觉语言模型（VLM）在交互式物理推理任务中泛化能力不足的问题，尤其在面对未见任务和环境时。指出了两个关键失败模式：一是产生与物理现实矛盾的幻觉式思维链（CoT）推理，二是模型推理与行动结果之间的错位。通过视觉行动结果推理对齐方法，有望提升VLM在物理世界中的可靠性和适应性，为机器人、智能仿真等产品提供更稳健的交互决策能力，降低部署成本。
