# Is Fixing Schema Graphs Necessary? Full-Resolution Graph Structure Learning for Relational Deep Learning

## 中文摘要
该论文探讨了关系深度学习（RDL）中图结构学习的必要性，提出全分辨率图结构学习方法，无需手动修正数据库模式图即可端到端训练图神经网络。技术要点在于自动学习关系数据库中的高阶连接关系，提升预测准确性。商业价值：降低企业在关系数据建模中的人工成本，加速AI应用落地（如推荐系统、欺诈检测）。产品创新：实现了从原始关系表到最优图结构的自动化转换，减少对专家经验的依赖。
