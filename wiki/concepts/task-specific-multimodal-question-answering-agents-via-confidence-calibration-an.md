# Task-Specific Multimodal Question Answering Agents via Confidence Calibration and Incremental Reasoning for QANTA 2026

## 中文摘要
本文提出一种针对QANTA 2026多模态问答竞赛的方法，通过置信度校准和增量推理提升系统在逐步揭示文本和图像下的金字塔式问答能力。技术要点包括：利用不确定性估计动态决定是否等待更多信息，结合视觉与语言模态进行渐进式推理。商业价值在于降低多模态系统的计算成本并提高实时问答的可靠性，适用于智能助手、教育题库、文档理解等场景。产品创新在于将增量推理与置信度校准结合，使AI能主动控制信息获取节奏，提升用户体验和效率。
