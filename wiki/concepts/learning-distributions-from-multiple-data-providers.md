# Learning Distributions from Multiple Data Providers

## 中文摘要
本文研究从多个异构且可能重叠的数据提供者中学习未知分布的问题，提出一种受限条件样本下的分布学习模型。学习者可获得一组固定的可查询集合，通过条件采样高效估计目标分布。该工作为分布式数据分析、隐私保护下的多方数据合作提供了理论基础，适用于联邦学习、用户画像构建、推荐系统等场景，有助于产品经理理解如何在不暴露原始数据的情况下整合多源信息，提升数据利用效率与模型准确性。
