# AutoSynthesis: An agentic system for automated meta-analysis

## 中文摘要
AutoSynthesis 是一个端到端的多智能体系统，旨在自动化传统上依赖人工的元分析过程。它通过协调多个AI智能体分工处理文献筛选、数据提取、效应量计算和异质性分析等步骤，突破了大规模证据合成的瓶颈。对AI产品经理而言，该技术展示了如何用多智能体协作模式将复杂的研究流程自动化，显著提升科研、医学、教育及政策制定的决策效率。其产品创新在于将分散的手动操作转化为可复用的智能体工作流，降低了专业壁垒，具备高商业价值。
