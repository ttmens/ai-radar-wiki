# Before You Think: System 0, AI-Mediated Cognition and Cognitive Colonization

## 中文摘要
该论文分析了三种理解AI对认知影响的框架：Tri-System Theory、Thinkframes和System 0。Tri-System Theory关注个体推理的AI介入，Thinkframes强调集体思考框架的演变，System 0则提出AI作为无意识认知层的新概念。这些框架为AI产品经理设计认知辅助工具、提升用户决策质量提供了理论支撑，尤其在智能助理、协作推理等场景中可指导产品实现更自然的AI-人类认知协同。
