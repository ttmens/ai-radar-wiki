# SkillOpt: Executive Strategy for Self-Evolving Agent Skills

## 中文摘要
本文提出 SkillOpt 策略，针对当前 Agent 技能依赖手工设计、一次性生成或松散自我修订的局限，主张技能应像深度学习优化器一样在反馈下持续训练与进化。该方法通过执行级优化，使技能能可靠地改进初始表现，提升 Agent 的自适应能力和长期效果。对产品经理而言，SkillOpt 可降低技能定制成本，实现 Agent 行为的自动调优，推动自主智能体的产品化落地。
