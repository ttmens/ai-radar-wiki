# You Only Need Minimal RLVR Training: Extrapolating LLMs via Rank-1 Trajectories

## 中文摘要
该研究揭示了基于可验证奖励的强化学习（RLVR）在大型语言模型中的参数轨迹几何结构，发现权重更新主要由秩为1的轨迹主导。通过仅需极少量RLVR训练步骤即可外推模型推理能力，大幅降低微调成本。产品经理可关注其降低强化学习训练门槛、加速推理优化的商业价值，尤其适用于需要快速迭代领域模型的场景。
