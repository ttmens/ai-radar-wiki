# Self-Evolving World Models for LLM Agent Planning

## 中文摘要
WorldEvolver提出了一种自我进化的世界模型，用于增强LLM智能体的长期规划能力。传统世界模型因预测不可靠而常被忽略或误用，导致决策质量下降。该模型通过在与环境交互中自动更新和优化自身的预测能力，提供更准确的行动后果预测，从而提升智能体的前瞻性和任务成功率。商业上，该技术可应用于自动化决策、机器人控制、游戏AI等需要长期规划的领域，减少人工标注成本，提升产品自主性和可靠性。产品创新点在于让模型自我进化，无需外部监督即可持续改进。
