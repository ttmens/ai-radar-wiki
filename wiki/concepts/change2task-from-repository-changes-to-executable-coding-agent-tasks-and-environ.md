# Change2Task: From Repository Changes to Executable Coding Agent Tasks and Environments

## 中文摘要
Change2Task 是一个自动化系统，能将代码仓库的变更转化为可执行的编码代理任务及配套环境，为训练、基准测试和持续评估提供源源不断的高质量数据。其核心价值在于解决编码代理规模化发展中的数据瓶颈，每个任务都包含真实软件状态、规格说明、开发工具和可靠验证机制，从而提升代理在真实开发场景中的能力，并支持更高效的评测与迭代。对 AI 产品经理而言，该方案可降低数据构建成本，加速智能编码产品的落地与进化。
