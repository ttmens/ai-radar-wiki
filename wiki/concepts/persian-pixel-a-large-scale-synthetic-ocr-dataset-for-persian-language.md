# Persian Pixel: A large-scale synthetic OCR dataset for Persian language

## 中文摘要
波斯语OCR技术因文字复杂性远落后于拉丁语，尽管全球超1.1亿人使用。该论文提出名为Persian Pixel的大规模合成数据集，通过合成数据生成方法解决真实标注数据匮乏问题，提升波斯语OCR模型性能。对AI产品经理而言，该技术可推动中东市场文档数字化、智能翻译等应用落地，降低数据采集成本，具备显著商业价值。
