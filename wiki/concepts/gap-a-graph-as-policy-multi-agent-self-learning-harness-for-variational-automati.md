# GaP: A Graph-as-Policy Multi-Agent Self-Learning Harness For Variational Automation Tasks

## 中文摘要
GaP 是一种将图结构作为策略的多智能体自学习框架，专门针对变分自动化任务。该框架结合了可解释的机器人编程与模型无关策略的开放世界适应性，使机器人能够在商业和工业应用中更可靠地工作。技术要点包括图策略表示、多智能体协作自学习机制以及面向变分任务的自动化。商业价值在于提升机器人编程的灵活性和鲁棒性，降低部署成本。产品创新体现在将图结构与强化学习融合，实现可解释性与适应性平衡，为复杂动态场景的自动化提供新思路。
