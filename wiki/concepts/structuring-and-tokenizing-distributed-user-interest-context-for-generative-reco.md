# Structuring and Tokenizing Distributed User Interest Context for Generative Recommendation

## 中文摘要
该论文提出了一种面向生成式推荐系统的用户兴趣上下文结构化与标记化方法。核心在于将用户历史行为中的分布式兴趣上下文进行结构化编码，并通过物品标记化（Item Tokenization）桥接语义与推荐目标，使模型能够生成用户下一步交互的预测。技术要点包括设计统一的标记化框架处理多源异构行为、利用分布式兴趣表示提升推荐准确性。商业价值体现在可应用于电商、内容分发等场景，通过更精准的预测增强用户留存与转化。产品创新在于从传统匹配范式转向端到端生成式范式，简化推荐流程并提升个性化程度。
