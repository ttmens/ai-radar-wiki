# Industry Classification of GitHub Repositories Using the North American Industry Classification System (NAICS)

## 中文摘要
该研究针对GitHub上数亿公共仓库缺乏标准化行业分类的问题，提出利用北美行业分类系统（NAICS）对仓库进行自动标注。技术要点包括构建分类模型，结合仓库描述、主题标签、代码依赖等多维特征，实现高精度行业映射。商业价值在于：为投资者、政策制定者和企业提供开源项目的产业分布洞察，支持创新地理分析与技术扩散研究。产品创新方面，可嵌入开发平台或分析工具，帮助用户按行业筛选仓库，或跟踪特定领域的开源趋势，提升数据驱动的决策效率。
