# Agora: Enhancing LLM Agent Reasoning Via Auction-Based Task Allocation

## 中文摘要
Agora 提出一种基于拍卖机制的任务分配方法，用于提升大语言模型（LLM）多代理系统的推理能力。传统框架通常采用粗颗粒度的任务-模型匹配，忽略了细粒度需求与专家模型或工具能力的差异。Agora 受经济学拍卖理论启发，通过让多个专家模型对子任务进行竞价，实现最优分配，从而整体提升推理质量和效率。该方法为构建更灵活、高效的 LLM 多代理系统提供了新思路，有助于降低开发复杂度、提高任务执行的准确性和鲁棒性，特别适用于需要多步骤推理和工具调用的复杂场景，具备显著的商业应用潜力。
