# EEVEE: Towards Test-time Prompt Learning in the Real World for Self-Improving Agents

## 中文摘要
EEVEE 是首个面向真实世界中多数据集任务流的大语言模型智能体测试时提示学习框架。传统方法仅限于单数据集场景，而实际应用要求模型能够应对动态变化的异构任务。EEVEE 通过在线提示学习，使智能体在推理过程中自我改进，无需重新训练即可适应新任务。该技术有望降低部署成本、提升AI agent的泛化能力与鲁棒性，为产品经理在构建自适应、持续学习的AI应用（如客服机器人、自动化助手）提供关键支撑。
