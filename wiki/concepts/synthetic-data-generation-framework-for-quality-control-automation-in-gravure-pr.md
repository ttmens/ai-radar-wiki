# Synthetic data generation framework for quality control automation in gravure printing

## 中文摘要
该论文提出用于凹版印刷质量控制自动化的合成数据生成框架，解决深度学习缺陷检测中标注数据稀缺问题。通过模拟真实印刷缺陷生成多样化合成样本，降低对昂贵人工标注的依赖，实现高精度自动质检。商业价值在于显著提升检测效率、降低成本，推动印刷业智能化转型。产品创新体现在将合成数据技术与工业质检场景深度耦合。
