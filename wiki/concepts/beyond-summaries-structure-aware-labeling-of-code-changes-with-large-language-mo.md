# Beyond Summaries: Structure-Aware Labeling of Code Changes with Large Language Models

## 中文摘要
该论文提出了一种利用大语言模型进行结构感知代码变更标签的方法，旨在解决现代软件开发中代码审查面临的规模与频率挑战。传统摘要式审查难以捕捉变更类型，而该方法通过分析代码结构自动识别重命名、重构等变更类别，提升审查效率与准确性。对于AI产品经理而言，该技术可直接集成到代码审查工具中，降低人工负担，加速开发流程，并可与AI代码助手互补，形成更智能的开发者工作流，具有显著的生产力提升价值和产品差异化潜力。
