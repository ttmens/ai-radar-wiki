# CompactionRL: Reinforcement Learning with Context Compaction for Long-Horizon Agents

## 中文摘要
CompactionRL提出了一种结合上下文压缩与强化学习的方法，解决长时程智能体在有限上下文窗口下的任务执行问题。通过用压缩后的历史交互状态替代原始轨迹，使LLM能够在不超出上下文限制的情况下持续学习与决策。该技术有望显著提升AI在复杂长期任务（如自动化工作流、多轮对话）中的实用性和效率，降低对硬件资源的依赖，为产品经理设计更智能、更持久的AI助手提供新思路。
