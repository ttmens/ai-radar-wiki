# Collaborative System Failure Prognostics via Federated Longitudinal-Survival Modeling

## 中文摘要
本文提出一种基于联邦纵向-生存建模的协作系统故障预测方法，通过联合多个分布式设备的传感器轨迹数据，在不共享原始数据的前提下，利用生存分析框架估计时变故障风险、可靠性及剩余使用寿命。该方法解决了传统集中式预测在数据隐私和通信成本上的瓶颈，适用于工业物联网、设备维护等场景。商业价值在于降低运维成本、提升系统可靠性；产品创新体现在将联邦学习与生存模型结合，实现隐私保护的预测性维护。
