# Learning Coordinated Preference for Multi-Objective Multi-Agent Reinforcement Learning

## 中文摘要
本文提出了一种协调偏好学习方法，用于多目标多智能体强化学习（MOMARL）场景。该方法旨在解决多个智能体在各自目标、观察和角色不同时产生的冲突，通过联合协调偏好实现团队决策优化。技术要点包括偏好向量共享、冲突检测与平衡机制。商业价值上，可应用于自动驾驶车队调度、多机器人协作、智能客服分工等需要多目标权衡的复杂系统，提升整体效率和适应性。产品创新在于将多目标偏好显式引入智能体交互，支持动态调整。
