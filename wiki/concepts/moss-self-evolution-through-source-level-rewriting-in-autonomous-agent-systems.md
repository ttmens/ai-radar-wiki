# MOSS: Self-Evolution through Source-Level Rewriting in Autonomous Agent Systems

## 中文摘要
MOSS是一种让自主智能体系统在部署后通过源代码级重写实现自我演化的方法。传统智能体部署后是静态的，无法从用户交互中学习，重复失败只能等待人工更新。MOSS允许智能体直接修改自身的源代码，包括API调用、数据结构等底层逻辑，而不仅限于技能文件或配置。这种能力使智能体能够自动适应新场景、修复错误、优化行为，极大降低维护成本并提升长期可靠性。对于AI产品经理，这代表着从“静态部署”到“持续进化”的范式转变，有望催生更自主、更灵活的AI产品。
