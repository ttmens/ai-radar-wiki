# PGT: Procedurally Generated Tasks for improving visual grounding in MLLMs

## 中文摘要
本文提出PGT（程序化生成任务）框架，旨在解决多模态大语言模型在细粒度视觉理解上的不足。通过自动生成结构化视觉推理任务，PGT能有效提升模型对图像细节的感知与定位能力。该框架简单灵活，可扩展至多种视觉任务，具有显著的产品创新潜力，例如在电商商品识别、医疗影像分析等场景中提升精度。同时，PGT降低了人工标注成本，为商业落地提供了高效的数据驱动方案。
