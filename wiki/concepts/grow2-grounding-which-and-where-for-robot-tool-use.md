# GROW$^2$: Grounding Which and Where for Robot Tool Use

## 中文摘要
该研究提出GROW²框架，解决机器人开放世界的工具使用问题：当缺少专用工具（如切蛋糕的刀）时，机器人能否用盘子等任意物品作为替代？技术核心在于同时推理“选择什么物体作为工具”以及“如何抓取和操作”，实现开放世界中的affordance grounding。商业价值在于大幅提升机器人在家庭、仓储等非结构化场景中的自适应能力，减少对专用工具包的依赖；产品创新在于将工具选择的语义理解与操作定位相结合，使机器人能够灵活应对未知任务。
