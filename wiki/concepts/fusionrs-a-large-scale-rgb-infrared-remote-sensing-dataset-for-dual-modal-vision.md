# FusionRS: A Large-Scale RGB-Infrared Remote Sensing Dataset for Dual-Modal Vision-Language Foundation Models

## 中文摘要
该论文提出FusionRS，一个大规模RGB-红外双模态遥感数据集，旨在弥补当前遥感视觉语言模型仅依赖RGB图像、忽略红外互补信息的不足。红外图像提供热强度结构等独特特征，可增强对地观测理解。该数据集支撑双模态视觉语言基础模型的训练与评测，有望推动环境监测、灾害评估、农业分析等场景的智能化升级，为产品经理在多传感器融合、低成本感知方案上提供新思路。
