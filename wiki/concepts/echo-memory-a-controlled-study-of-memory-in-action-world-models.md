# Echo-Memory: A Controlled Study of Memory in Action World Models

## 中文摘要
Echo-Memory 是一项针对动作条件世界模型中记忆机制的受控研究。这类模型能够根据首帧、文本提示和相机动作序列生成多段视频，但其主要瓶颈在于记忆能力而非局部图像合成。通过控制实验，该研究揭示了记忆在长视频生成中的关键作用，为改进世界模型的长期上下文理解提供了方向。该工作对AI产品经理的启示在于，记忆机制是提升视频生成连贯性和可控性的核心技术，有望推动创意工具、虚拟世界构建等产品创新。
