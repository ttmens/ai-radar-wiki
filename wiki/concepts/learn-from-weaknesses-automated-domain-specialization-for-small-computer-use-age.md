# Learn from Weaknesses: Automated Domain Specialization for Small Computer-Use Agents

## 中文摘要
本文提出一种自动化领域专业化方法，用于提升小型计算机使用代理（CUA）在特定软件领域的性能，而非依赖昂贵的大型专家模型。通过识别并针对性训练小型CUA的薄弱环节，该方法能有效降低部署成本，同时提升领域内任务完成率。对于AI产品经理，这意味着可以以更低成本打造专用代理，无需为每个领域训练大模型，具有显著的商业价值。产品创新在于从弱点学习而非全面增强，实现更高效的能力提升。
