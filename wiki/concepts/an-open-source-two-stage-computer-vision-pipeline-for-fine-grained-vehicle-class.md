# An Open-Source Two-Stage Computer Vision Pipeline for Fine-Grained Vehicle Classification using Vision Transformers

## 中文摘要
该论文提出一个开源的两阶段计算机视觉流水线，利用Vision Transformers实现细粒度车辆分类，旨在识别超车碰撞中影响骑行者伤害严重程度的车身类型。与仅提供粗略类别的标准目标检测不同，该流水线能精确区分多种车辆子类，填补了交通安全自动化工具的空白。技术要点包括两阶段架构（检测+精细分类）和Transformer注意力机制。商业价值体现在保险定损、自动驾驶风险评估及城市交通安全监测等场景。产品创新在于开源实现和针对特定安全需求的细粒度分类能力。
