# A Multi-Fidelity Convolutional Autoencoder-Transfer Learning Framework for Guided-Wave-Based Damage Diagnosis Using Large Simulated and Limited Experimental Datasets

## 中文摘要
该论文提出一种基于多保真卷积自编码器与迁移学习的框架，用于导波结构健康监测（GWSHM）。核心创新在于：利用大量模拟数据预训练模型，再通过少量实验数据微调，解决实际场景中标注实验数据稀缺的问题。技术要点包括多保真仿真、卷积自编码器特征提取及迁移学习适配。商业价值在于降低工程结构损伤诊断系统的部署成本，加速从实验室到现场的应用落地，尤其适用于航空航天、基础设施等关键设施的早期故障检测。产品创新体现在模拟与实验数据协同训练，提升了模型在真实环境下的鲁棒性和泛化能力。
