# Barzilai-Borwein Fails Superlinear Convergence on an Open Set of Quadratics for Every Dimension $n\geq 4$

## 中文摘要
该论文研究了Barzilai-Borwein（BB）方法在连续优化中的收敛性。BB方法虽在实际中表现优异，但其理论基础薄弱，尤其对于严格凸二次问题及初始化是否几乎总能实现超线性收敛这一核心问题，至今未解。论文证明：当维度n≥4时，存在一个开集的二次型函数集，使得BB方法无法实现超线性收敛。这一发现揭示了BB方法在高维优化中的局限性，对AI领域的优化算法设计具有理论指导意义，但短期内商业价值较低。
