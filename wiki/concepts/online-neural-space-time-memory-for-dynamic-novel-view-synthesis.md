# Online Neural Space Time Memory for Dynamic Novel View Synthesis

## 中文摘要
该论文提出在线空间时间记忆网络，解决动态新视角合成中持久记忆与实时性的权衡问题。通过测试时训练（TTT）机制，系统能在多视角流视频中实时维护长期记忆，有效重建临时遮挡区域，无需离线预处理。技术核心在于将空间时间信息编码为可在线更新的记忆表示，实现高效上下文融合。产品创新点在于为AR/VR、沉浸式直播、远程协作等场景提供实时、高保真的动态视角合成能力，降低了部署门槛，商业价值体现在提升用户体验和拓展实时3D视觉应用边界。
