# Learning Red Agent Policy from Observations for Neurosymbolic Autonomous Cyber Agents

## 中文摘要
该论文提出了一种基于强化学习的自主网络防御代理方法，采用神经符号AI结合行为树与可学习组件（LECs），从观察中学习红队（攻击方）策略。技术要点包括利用离线数据训练、神经符号推理实现可解释性与适应性；商业价值在于提升企业网络安全自动化的实时响应能力，降低人工成本；产品创新体现在将符号逻辑与深度学习融合，使AI代理能在复杂网络中自主决策，适用于SOC自动化、EDR等领域。
