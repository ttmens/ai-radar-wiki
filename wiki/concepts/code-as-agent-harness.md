# Code as Agent Harness

## 中文摘要
该论文提出“Code as Agent Harness”概念，强调在智能体系统中，代码不仅是LLM的生成目标，更成为智能体操作的基础框架。通过将代码作为智能体的“操作基质”，可显著提升LLM在复杂任务中的执行能力，从编程竞赛到企业级软件工程均适用。这一思路为产品经理提供了新视角：利用代码驱动智能体自主完成编码、调试、部署等全流程，有望降低开发门槛、加速功能迭代。商业价值在于构建更强大的AI编码助手与自动化开发工具，推动软件工程效率革命。
