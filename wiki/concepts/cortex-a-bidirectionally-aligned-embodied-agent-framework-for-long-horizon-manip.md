# Cortex: A Bidirectionally Aligned Embodied Agent Framework for Long-horizon Manipulation

## 中文摘要
Cortex是一个面向长时域操作任务的双向对齐具身代理框架。针对当前视觉-语言-动作(VLA)模型因马尔可夫性（仅依赖当前观测）而在长期任务中表现不佳的问题，Cortex采用层次化双系统架构，通过双向对齐机制弥补高层规划与低层执行之间的鸿沟。该框架不仅提升了机器人执行复杂、长期操作任务的成功率，还为具身智能产品的商业化提供了可扩展的架构范式，尤其适用于自动化仓储、家庭服务等需要连续决策的场景。其产品创新在于将规划与执行紧密耦合，减少错误累积。
