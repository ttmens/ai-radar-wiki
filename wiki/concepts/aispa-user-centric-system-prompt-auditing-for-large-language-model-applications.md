# AISPA: User-Centric System Prompt Auditing for Large Language Model Applications

## 中文摘要
AISPA提出了一种以用户为中心的系统提示审计方法，针对大型语言模型应用中开发者配置的System Prompt（系统提示）缺乏公开透明的问题。该技术旨在帮助用户、监管者及产品团队理解并审计AI应用的隐藏行为逻辑，弥补商业化部署中的信任与责任缺口。对产品经理而言，其价值在于通过系统化审计提升AI产品的可解释性、合规性和用户信任度，同时为产品设计中的提示词管理提供新的治理视角，是AI应用走向规模化落地的重要基础设施。
