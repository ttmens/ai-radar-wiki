# 小红书增长策略文档

## 一、账号定位与人设

### 1.1 账号定位
- **领域**：AI产品经理 + 效率工具
- **差异化**：每日AI情报 + PM视角解读
- **价值主张**：帮PM和职场人跟上AI趋势，提升效率

### 1.2 人设定位
- **人设名称**：AI Radar（AI雷达）
- **人设标签**：AI探索者 / PM视角 / 每日情报
- **语言风格**：口语化、有洞察、接地气
- **视觉风格**：珊瑚红+白底，卡片式，信息密度高

### 1.3 内容支柱（3个固定栏目）
1. **🔥 AI日报**（每日）：3-5条AI大事件，快速概览
2. **💡 PM洞察**（每周2-3次）：深度解读1个趋势，带PM思考
3. **🛠️ 工具推荐**（每周1-2次）：实用AI工具测评

## 二、内容策略

### 2.1 标题公式（高转化率）

**万能模板：**
1. 「X个XX，第X个绝了」→ 🔥 今天AI圈3件大事，第2个太重要了
2. 「别再XX了！试试这个」→ ❌ 别再手动整理AI新闻了！这个日报绝了
3. 「XX人必看的XX」→ 💡 PM必看！这3个AI趋势影响你的产品
4. 「用XX，我X分钟搞定X小时」→ 🚀 用这个AI工具，我1小时做完3天的工作
5. 「99%的人不知道的XX」→ 💎 99%的PM不知道的AI趋势

**标题规则：**
- 字数：18-25字（移动端两行）
- 必含：数字(1-2个) + emoji(1-2个) + 情绪词(1个)
- 情绪词库：绝了、封神、炸裂、救命、真香、离谱、太强了、必收藏

### 2.2 正文结构（黄金模板）

```
[钩子] 1-2句，制造共鸣或抛出痛点
  ↓
[核心] 分点列举，3-5个要点（用emoji编号）
  ↓
[洞察] PM视角解读（1-2句）
  ↓
[CTA] 引导互动（评论/收藏/关注）
  ↓
[标签] 5-10个，大+中+长尾组合
```

**正文规则：**
- 字数：300-500字（图文笔记最佳）
- 段落：每段≤3行，用emoji分隔
- 口语化：像跟朋友聊天，避免学术腔
- 关键信息：用【】或加粗突出

### 2.3 标签策略

**标签组合（每篇7-10个）：**
- 2个大标签（10亿+浏览）：#AI工具 #效率提升
- 2-3个中标签（1-10亿）：#ChatGPT #程序员日常 #职场干货
- 2-3个长尾（1000万-1亿）：#AI写代码 #自动化办公 #AI产品经理
- 1-2个热点：#最新AI #AI日报

**标签规则：**
- 放在正文最末尾
- 不堆砌无关标签
- 优先选择"参与人数多但笔记数少"的标签

## 四、互动优化（提升CES评分）

### 4.1 CES评分权重
```
关注(8分) > 评论(4分) = 转发(4分) > 收藏(1分) = 点赞(1分)
```

**重点优化：评论数 + 收藏率**

### 4.2 互动引导话术

**引导评论（提升CES）：**
- 💬 你觉得哪条最影响你的工作？评论区聊聊
- 💬 这条趋势对你做产品有什么启发？
- 💬 你们最想看哪个工具的详细教程？
- 💬 你觉得AI会取代你的工作吗？

**引导收藏（提升长尾流量）：**
- 🔖 建议先收藏，用到的时候找得到
- 🔖 收藏起来，以后一定用得上
- 🔖 先收藏，下期教大家怎么用

**引导关注（提升粉丝）：**
- ✨ 关注我，每天分享AI干货
- ✨ 关注我，不错过AI趋势
- ✨ 关注我，一起成为AI时代的PM

### 4.3 发布后运营
- **发布后30分钟**：在线回复评论（提升初始CES）
- **发布后2小时**：检查数据，回复新评论
- **发布后24小时**：总结数据，优化下一篇

## 六、视觉设计规范

### 6.1 品牌色
- **主色**：珊瑚红 #FF385C（强调色）
- **辅色**：紫色 #7C3AED（洞察类）
- **背景**：浅粉 #FFF5F5 / 浅紫 #F5F3FF
- **文字**：黑色 #1A1A1A / 深灰 #333333

### 6.2 卡片模板
- **尺寸**：1080×1440px（3:4竖版）
- **圆角**：32px
- **阴影**：0 4px 24px rgba(0,0,0,0.06)
- **字体**：标题46-50px Bold，正文32-34px Regular

### 6.3 视觉元素
- **编号**：红色圆角方块（56×56px）
- **标签**：彩色圆角标签（红/绿/紫）
- **分隔线**：3px主色线
- **图标**：emoji为主（🔥💡🛠️📊💬）

## 七、数据追踪

### 7.1 核心指标
- **曝光量**：笔记被推荐的次数
- **点击率**：曝光→点击的转化率（目标>5%）
- **互动率**：点赞+收藏+评论/曝光（目标>3%）
- **粉丝增长**：每日新增粉丝数

### 7.2 优化循环
- **每周复盘**：分析数据，找出爆款规律
- **A/B测试**：测试不同标题、封面、发布时间
- **迭代优化**：根据数据调整内容策略
